## 🚀 使用指南

### 快速开始

```bash
# 1. 安装依赖
pip install torch torchvision

# 2. 配置环境(可选)
# 注意：参考适配器声明 production_ready = False，工厂与生产配置校验都会拒绝它，仅用于本地打通链路。
export SCENARA_FASHION_ENGINE_FACTORY=scenara.domains.fashion.reference_adapter:create_reference_fashion_engine

# 3. 启动服务
python start.py

# 4. 调用 API
curl -X POST http://localhost:8000/api/v1/parse/image \
  -F "file=@cosplay.jpg" \
  -F "domain=fashion" \
  -F "min_confidence=0.5"
```

### API 参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `min_confidence` | float | 0.5 | 最低置信度阈值 |
| `detect_cosplay` | bool | true | 是否识别 Cosplay |
| `detect_clothing` | bool | true | 是否识别服装风格 |
| `detect_accessories` | bool | true | 是否识别配饰 |
