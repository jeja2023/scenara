# ADR 0003：中文品牌统一为“景枢”

- 状态：已接受
- 日期：2026-07-30

## 背景

英文品牌 Scenara 和 `scenara` 技术标识已经进入仓库名、SDK、镜像、API、数据库表与环境变量。中文品牌需要表达平台对视觉能力的统一接入、解析、调度、输出和治理职责。

## 决策

产品完整名称统一为 **Scenara 景枢**，产品类别统一为“企业视觉 AI 中枢平台”。历史中文品牌“景析”停止用于当前产品表面，只允许出现在本 ADR、升级方案和更新日志等明确标记的迁移记录中。

英文品牌、仓库名、Python/TypeScript 包名、Docker 镜像、`/api/v1`、数据库表前缀和 `SCENARA_*` 环境变量保持不变。

## 影响与回滚

品牌迁移覆盖 README、品牌规范、中文文字标、控制台标题、OpenAPI 描述、SDK 与部署文档、示例客户端。抽象 `S` 图形标志、颜色、安全留白与小尺寸规范保持不变。

若正式商标审查要求调整中文名称，必须通过新的 ADR 决策；不得修改技术标识来完成中文品牌回滚。
