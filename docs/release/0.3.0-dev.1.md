# Scenara 0.3.0-dev.1 发布说明

发布日期：2026-07-31

`0.3.0-dev.1` 是媒体解析能力全面升级的开发快照，对应 Python 版本 `0.3.0.dev1`。它不是正式 `1.0.0` 生产发行版；合法模型制品、固定评估集、目标 GPU、隔离网络、离线安装、恢复演练、软件许可证法务批准和具名签署证据仍由严格发布门禁失败关闭。

## 主要变更

### 视频与实时流抽帧策略扩展

- 新增 `keyframe`（已解码 I 帧）、`scene_change`（灰度直方图场景切换）、`uniform`（均匀分布）三种采样策略，与原有 `interval` 并列；真实 GOP 样本使用 PyAV 独立交叉验证关键帧序列。
- 新增时间窗口参数 `sample_start_ms` / `sample_end_ms`；文件视频优先使用 `seek` 跳帧，失败时逐帧跳过。
- 新增 `frame_max_edge` 参数，对采样帧等比缩放，减少内存占用。
- PDF 解码新增 `page_scale` 参数（默认 1.5×），控制 pypdfium2 渲染倍率。
- 文件视频优先使用 decoder PTS，实时流使用跨重连严格单调的作业时钟；`timestamp_source` 明确记录时间戳来源。
- 长算子在执行期间持续同步 pause/cancel 状态，解码线程在读取、重连与退避边界合作暂停或退出并释放捕获器。
- 媒体元数据新增 12 个可观测字段：`sample_strategy`、`keyframe_count`、`scene_change_count`、`frame_max_edge`、`decode_seek_used`、`reconnect_count`、`elapsed_ms`、`timestamp_source` 等。

### 新 API 端点

- `POST /api/v1/parse/document`：专用 PDF 文档解析端点，接受 `max_units`、`page_scale` 参数。
- `POST /api/v1/parse/video` 扩展表单参数：`sample_strategy`、`sample_start_ms`、`sample_end_ms`、`scene_change_threshold`、`frame_max_edge`、`page_scale`。
- 图片、视频和文档快捷入口的 `pipeline_version` 改为可选；省略时由服务端选择唯一 active 版本。流入口的 `pipeline.version` 同样可省略，显式版本仍用于可复现绑定。
- 文档入口使用独立的 `ParseDocumentResponse`，产品目录显式列出图片、视频、PDF 和实时流四个解析端点。

### 控制台升级

- **解析工作台（ParseView）**：新增 PDF 模式标签页；采样策略、时间窗口、帧缩放、流重连和连接/读取超时控件；SSE 使用统一连接配置并支持断流轮询接管；暂停、恢复和取消持续跟踪到稳定状态；Canvas 叠加边界框（语义配色 + 置信度标签，支持 OCR 多边形）；JSON/CSV 结果导出；告警折叠面板。
- **SDK**：Python 与 TypeScript 快捷接口覆盖图片、PDF、视频和实时流，完整序列化采样、窗口、缩放及流韧性参数；OpenAPI 在入口层生成 `SampleStrategy` 枚举。
- **媒体管理（MediaView）**：资产类型筛选、元数据展开行、批量删除、视频内嵌播放预览。
- **运行管理（RunsView）**：汇总统计卡、进度条列、耗时列、仅有活跃运行时才轮询的自动刷新。

### 数据模型与契约

- `models.py` 新增 `SampleStrategy` 枚举。
- `media_batch.py` 新增 `SamplePlan` 冻结数据类，集中校验采样参数。
- `DecodeMediaOperator` 版本升级至 `1.1.0`，完全向后兼容。
- `labels.ts` 新增 `labelSampleStrategy()`；`types.ts` 同步新增字段；`OcrBlock` 补充 `polygon` 字段。
- OpenAPI（`docs/openapi.json`）与 TypeScript SDK（`sdk/typescript/`）已重新生成并同步。

## 升级说明

1. 将应用镜像标签切换到 `0.3.0-dev.1`。
2. 重新运行数据库迁移（本次无新迁移脚本，`0001`–`0003` 已在 `0.3.0-dev.0` 全部执行）。
3. Python SDK 更新：`pip install scenara-sdk==0.3.0.dev1`。
4. TypeScript SDK 更新：重新构建或引用新版 dist。

## 发布边界

本次更新完成的是媒体解析能力、控制台工作台和相关契约的工程实现与自动化验证，不等同于 Scenara 1.0 已获得生产发布资格。只有 `docs/release/evidence/manifest.json` 聚合的九类报告全部绑定同一发布身份，由责任人执行、校验和签署，并通过严格发布门禁后，才能将对应能力标记为 Qualified 或 Released。
