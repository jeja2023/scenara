# Scenara 0.3.0-dev.2 发布说明

发布日期：2026-07-31

`0.3.0-dev.2` 是媒体解析、控制台工作台、公共契约和发布证据整理后的工程资格快照。它不是正式 `1.0.0` 生产发行版；合法模型制品、固定评估集、目标 GPU、隔离网络、离线安装、恢复演练、软件许可证法务批准和具名签署证据仍由严格发布门禁失败关闭。

## 升级说明

1. 将应用、Console、Python SDK、TypeScript SDK 和 Compose 默认镜像标签切换到本版本。
2. 重新执行 `python scripts/export_openapi.py` 与 `python scripts/generate_typescript_sdk.py`，确认公共契约无漂移。
3. 数据库迁移沿用已执行的 `0001`–`0003`，本版本没有新增迁移脚本。
4. 生产环境仍必须显式提供经批准的模型包和发布证据，不能以开发适配器替代。

## 本版本变更

### 媒体解析

- 图片、视频文件、PDF 文档和视频流统一绑定版本化 Pipeline、Run 和 Result。
- 视频支持 `interval`、`keyframe`、`scene_change`、`uniform` 采样策略、时间窗口、关键帧交叉验证和帧最大边长缩放。
- 文件视频优先使用解码器 PTS；实时流使用跨重连单调作业时钟，并记录 `timestamp_source`、重连次数、seek、采样计数和耗时元数据。
- PDF 支持 `page_scale`，所有媒体解码边界持续响应暂停、恢复和取消。
- 暂停耗时不计入算子超时；取消会从请求到稳定终态持续跟踪。

### API 与 SDK

- 新增独立 `ParseDocumentResponse`，修正文档入口响应契约。
- 图片、视频、文档和流入口的 Pipeline 版本可省略；服务端会解析唯一 active 版本，显式版本仍用于可复现绑定。
- Python 图片 SDK 补齐 Pipeline 和幂等参数；Python/TypeScript 视频、文档、流 SDK 补齐媒体参数和可选版本序列化。
- 产品目录、OpenAPI、TypeScript 生成代码、Python SDK 和 TypeScript SDK 同步更新。

### 控制台

- ParseView 完整覆盖图片、视频、PDF 和视频流工作流，包含采样、窗口、帧缩放、重连、连接/读取超时、SSE 断流接管、暂停、恢复、取消、JSON/CSV 导出和告警面板。
- MediaView 从 Pipeline 目录读取 active 版本，不再硬编码旧版本。
- 运行和结果页面使用统一生命周期及结果查询契约，桌面和移动视口均通过验收。

## 发布边界

本版本完成的是工程实现、公共契约和自动化验证，不等同于 Scenara 1.0 已获得生产发布资格。严格发布前必须由责任人提交并签署 `backup_restore`、`gpu_capacity`、`integration_services`、`model_rights`、`ocr_evaluation`、`offline_install`、`portrait_evaluation`、`security_assessment`、`software_license_approval` 九类证据，并由 `docs/release/evidence/manifest.json` 绑定同一发布身份和 SHA-256。

## 密钥扫描误报修复

- Gitleaks 误报来源确认是公开的 OpenAPI 契约 SHA-256 摘要，不是访问凭据或私密材料。

- 新增仓库契约回归测试，确保 `tsc` 生成声明文件时不会再次丢失该标记；不使用文件级或规则级宽泛白名单。
