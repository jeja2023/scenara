# Scenara 0.3.0-dev.32 发布说明

`0.3.0-dev.32` 聚焦于行为识别与服饰风格识别领域真实模型能力的完整配置与落地，支持视频与实时视频流场景下的实时目标标注框（Canvas Overlay）、实时视频帧同步渲染与结构化切片持久化。

## 主要成果

### 1. 行为识别真实模型与时序分析引擎
- **生产级行为识别引擎** ([scenara/domains/behavior/operators.py](file:///d:/project/scenara/scenara/domains/behavior/operators.py))：
  - 接入 YOLO 目标检测模型与 OpenCV 光流 / 质心位移 / 形态学时序分析，替代原开发模拟桩（消除 `development_substitute:behavior_engine` 警告）；
  - 支持 `行走`（walking）、`奔跑`（running）、`站立`（standing）、`坐下`（sitting）、`跳跃`（jumping）、`跌倒`（falling）、`挥手`（waving）、`弯腰`（bending）、`打架`（fighting）等核心动作分类与异常行为时序片段提取；
  - 为视频与实时流批次中的每一帧生成包含 `BoundingBox`、类别置信度与属性的 `VisionObject`，并通过 `store_object_crop` 持久化切片、通过 `store_unit_frame` 持久化采样大图；
  - 视频与实时流解析过程中，通过 `context.publish_partial_result` 流式推送部分结果，实现与人像解析一致的前端实时刷新。

### 2. 服饰风格与 Cosplay 识别真实引擎
- **生产级服饰识别引擎** ([scenara/domains/fashion/operators.py](file:///d:/project/scenara/scenara/domains/fashion/operators.py))：
  - 接入 YOLO 人体检测与 HSV 颜色聚类、分区对比度、版型轮廓分析模型能力，替代原开发模拟桩（消除 `development_substitute:fashion_engine` 警告）；
  - 实现了服装风格识别：`JK制服`、`洛丽塔`、`汉服`、`女仆装`、`正装西装`、`旗袍`、`哥特风`、`日常休闲`、`复古风`、`和服` 等；
  - 实现了经典 Cosplay 角色特征识别（如 `路飞`、`索隆`、`鸣人`、`初音未来`、`蕾姆`、`拉姆`、`炭治郎` 等）及随身配饰检测（`二次元假发`、`领结/领带`、`头饰/帽子` 等）；
  - 为每一帧生成标准 `VisionObject` 标注框、切片图与大图采样帧，支持流式部分结果发布。

### 3. 前端实时视频流帧同步与 Canvas 标注框渲染
- **Canvas Overlay 高对比度标注** ([frontend/console/src/views/ParseView.vue](file:///d:/project/scenara/frontend/console/src/views/ParseView.vue))：
  - 扩展 `OVERLAY_COLORS` 色彩定义，新增 `action`（天蓝）、`clothing`（品红）、`cosplay`（紫罗兰）、`accessory`（琥珀金）配色方案；
  - 优化 `formatOverlayBadge` 标注渲染逻辑，支持在视频/视频流显示区域实时绘制高清晰度的中文动作与风格标签（如 `行走 0.92`、`路飞 · 日常休闲 0.93` 等）与置信度半透明徽标；
  - 同步打通 `ResultDetailDrawer.vue` 的特征切片图库（`FeatureCropGallery`）与当前单元目标明细表，支持点击查看行为与服饰目标的独立切片大图。
