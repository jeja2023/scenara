# Scenara 0.3.0-dev.25 发布说明

**发布日期**：2026-08-21

`0.3.0-dev.25` 是面向《景枢平台总体开发规范》的向量基础设施与发布契约收口版本。版本新增可配置的 Qdrant `FeatureStore` provider，并同步所有生成契约、部署默认值和发布证据绑定。该版本仍是开发版，不宣称 1.0 生产资格已完成。

## 主要变更

### Qdrant 向量后端

- 新增 `scenara/infrastructure/qdrant_features.py`，通过 Qdrant REST API 实现平台 `FeatureStore` 契约。
- 支持 cosine、L2 和 inner-product 三种距离；Qdrant provider score 映射回平台统一的 score/distance 语义。
- 所有向量记录携带 tenant、project、feature-space 和原始 feature ID；查询过滤强制包含租户/项目，并排除过期记录。
- 使用确定性 provider UUID 和空间元数据点，进程重启后可发现 collection 并恢复 `FeatureSpace` 契约。
- `SCENARA_QDRANT_URL` 非空时，PostgreSQL 状态后端自动选择 Qdrant；未配置时保持 pgvector 路径。

### 版本与契约

- Python 包版本：`0.3.0.dev25`。
- npm 根包、Console、TypeScript SDK、Compose、Kubernetes 和离线包标签：`0.3.0-dev.25`。
- 重新导出 `docs/openapi.json` 并生成 TypeScript SDK；证据清单绑定 OpenAPI SHA-256 `3b53275e54ab6146cfa11238b85854cf4b4f89f69ea02676ca4c9f610773b1f2`。

### MLOps 边界

- 新增 Triton HTTP `ModelAdapter`，支持 readiness、版本化 JSON inference、不可变模型元数据和 fail-closed 错误处理。
- 新增 MLflow REST 记录器，将模型包摘要、能力和评估证据写入实验 Run。
- 新增模型健康阈值触发的受控自动回滚 API；仅在样本数达到阈值且健康快照建议回滚时选择最新合格 retired 版本。

### 独立 Data 开发服务

- 新增 `scenara_data` 独立进程、`Dockerfile.data` 和 `deploy/compose.data.yml`，承接 Dataset、Dataset Version、Sample、Annotation、Provider 和 Hard Sample intake 内部 API。
- 服务使用独立的租户/项目键空间、服务令牌和幂等键；Core 不共享其存储对象。
- 当前实现用于开发与切流前契约验证；生产 PostgreSQL/对象存储、迁移导入、影子读、备份恢复和回滚演练仍需独立 Data 环境证据。

## 验证结果

- Qdrant、MLOps 和 Data 定向契约测试：`12 passed`。
- 全量 Python：`263 passed, 12 skipped`；OpenAPI/TypeScript SDK 漂移检查、implementation-only release gate、development gate、Ruff 和 Mypy 通过。
- `docker compose -f deploy/compose.data.yml config` 通过；Core `HttpDataPlatformClient` 与 standalone Data app round-trip 通过。
- 隔离 Docker PostgreSQL/pgvector、Redis、MinIO 集成回归（`.venv`）：`12 passed, 0 skipped`。
- 严格发布门禁仅因 `gpu_capacity`、`model_rights`、`ocr_evaluation`、`offline_install`、`portrait_evaluation` 五项真实外部资格 pending 而 fail-closed。

## 已知限制

- `gpu_capacity`、`model_rights`、`ocr_evaluation`、`offline_install`、`portrait_evaluation` 仍需真实目标环境、权利文件或固定评估集证据。
- Qdrant 适配器代码已完成，但真实集群的容量、备份恢复、升级兼容和隔离验收仍是部署门禁。
- 独立 `scenara-data` 服务的迁移导入、影子读、回滚和生产备份恢复仍由 Data 仓库及切流演练负责。
