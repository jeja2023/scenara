# Scenara 0.3.0-dev.33 发布说明

`0.3.0-dev.33` 重点聚焦于全领域重点区域（ROI）交互防护与算子端防穿透、OCR 视觉排版 1:1 底图对照双模还原（透视叠图与左右双屏），以及任务取消过程中的切片结果保全与 404 状态规范化治理。

## 主要成果

### 1. 全领域 ROI 圈选交互与算子端防穿透
- **前端交互事件防护与拖拽防劫持** ([frontend/console/src/views/ParseView.vue](file:///d:/project/scenara/frontend/console/src/views/ParseView.vue))：
  - 彻底阻断浏览器 HTML5 原生图片拖拽（`dragstart`）对画板的事件吞没，解决鼠标按下拖动时产生半透明重影且无法生成选框的顽疾；
  - 新增专用透明防劫持捕获层（`roi-drawing-layer`，`z-index: 20`），结合全局 `window` 指针监听，确保快速拖拽出播放容器外部释放鼠标时依然精准完成选区计算；
  - 圈选模式下自动阻断底层 `<video controls>` 控制条与文本选中高亮干扰；
  - 在历史任务回显与页面刷新时，从 `parameters.roi` 自动恢复还原 `selectedRoi.value`，杜绝选区丢失回退为全图解析。
- **行为识别与人像算子端精准过滤** ([scenara/domains/behavior/operators.py](file:///d:/project/scenara/scenara/domains/behavior/operators.py), [scenara/domains/portrait/analysis.py](file:///d:/project/scenara/scenara/domains/portrait/analysis.py))：
  - 修复行为识别算子：当配置 ROI 且区域内无活动人体时，自动清空 `chunk_actions` 与 `chunk_anomalies`，杜绝因空列表判断失真回退到全图运动检测误报动作；
  - 修复人像分析算子：时序轨迹流 `domain_payload.tracks` 严格同步按 ROI 内的有效人员 ID 实施对齐过滤。

### 2. OCR 视觉排版 1:1 底图对照与双模对比
- **底图加载链路打通与内存缓存** ([frontend/console/src/components/ResultDetailDrawer.vue](file:///d:/project/scenara/frontend/console/src/components/ResultDetailDrawer.vue))：
  - 彻底解决 OCR 详情抽屉中点击“底图对照”未拉取原图、仅显示半透明灰底的问题；
  - 优先拉取当前单元或海报幻灯片的高清大图切片（`/api/v1/runs/{run_id}/artifacts/{frame_artifact_id}`），若未产生切片自动回退拉取原始输入资产预览图（`/api/v1/media/assets/{asset_id}/preview`）；
  - 引入客户端内存缓存（`underlayCache`），切换单元或重开底图实现毫秒级秒开响应。
- **透视叠图模式（Overlay）**：
  - 利用 CSS `::before` 伪元素将原始文档底图以 1:1 比例注入排版容器底层；
  - 识别出的文本块以半透明蓝色磨砂框与原始文档文字 **100% 像素级贴合叠加**，鼠标悬停时高亮聚焦；
  - 提供 **20% ~ 100% 底图清晰度滑块**，支持自由调节底图透出强度。
- **左右双屏模式（Split View）**：
  - 提供 `[ 左右双屏 ]` 切换按钮，左侧展示原始未裁剪的高清文档图，右侧展示 1:1 仿真自适应 HTML 排版，满足专业核对审阅需求。

### 3. 任务取消结果保全与 404 报错杜绝
- **后端服务保全机制** ([scenara/platform/services.py](file:///d:/project/scenara/scenara/platform/services.py))：
  - 任务取消（`cancel`）时不再暴力清除已生成的中间切片与帧，完整保留已分析产出的单元结果并支持正常加载；
  - 优化 `/api/v1/runs/{run_id}/result` 结果索引，未完成或无单元任务合规返回标准空 `ResultEnvelope`，杜绝浏览器控制台 404 报错。
- **工作台响应式联动**：
  - 解析工作台（`ParseView.vue`）“最近运行”列表增加状态与进度响应式监听，状态变迁即时同步，任务结束自动刷新最新状态。
