# Scenara 0.3.0-dev.38 发布说明

`0.3.0-dev.38` 重点聚焦于**接入与权限（IAM）产品目录标准化与 9 大核心产品对齐**、**全站弹窗体验扩容与自适应展示优化**、**弹窗交互统一（移除冗余关闭按钮）**、**权限标识列纯净视觉重构**以及**前后端全链路 UI 中文化**。

## 主要成果

### 1. 接入与权限产品目录标准化与 9 大核心产品对齐 (Product Catalog Standardization)
- **核心产品矩阵梳理**：
  - 彻底梳理并标准化平台 9 大核心产品定义：`parse`（智能视觉与文档解析）、`search`（综合与多模态检索）、`model`（AI 模型管理与准入）、`data`（数据资产与数据集治理）、`flow`（智能分析流水线编排）、`index`（特征与向量索引底座）、`api`（开放应用接口）、`sdk`（多语言开发工具包）、`console`（平台共享控制台）；
  - 排除并过滤非独立子领域（`train`, `surveillance`, `media`）及实验门禁产品（`edge`, `agent`），确保项目产品授权、角色定义、服务账号与 API 密钥授权范围精准清晰。
- **全链路中文化与能力范围（Scopes）完善**：
  - 在 `scenara/platform/product_catalog.py` 与 `labels.ts` 中对齐并规范所有产品的中文名称、领域说明、职责摘要与能力范围清单；
  - 汉化并规范了 `OCR 文档解析与识别`、`Qdrant 向量特征库多租户适配`、`OpenAPI 标准契约`、`v1 接口路由`、`Webhook 事件推送`、`Python/TypeScript SDK 客户端` 等核心能力项。

### 2. 弹窗尺寸扩容与排版自适应优化 (Modal Sizing & Anti-Overflow Redesign)
- **弹窗容器宽度扩容**：
  - 普通中型弹窗（如新建组织、新建项目、新建用户、向项目分配成员）宽度由 `520px/620px` 升级为 `780px`（`min(780px, 95vw)`）；
  - 大型配置弹窗（如新建服务账号、签发 API 密钥、保存产品授权、新建安全角色）宽度由 `720px` 扩容至 `980px`（`min(980px, 96vw)`）。
- **适用产品选择区域标准化（3 列规整网格）**：
  - 优化角色、服务账号、API 密钥弹窗中的产品范围选择器，由原来的自适应拥挤窄列调整为 **标准的 3 列卡片网格（3×3 布局）**；
  - 单项宽度扩充至 `290px+`，如「数据资产与数据集治理」、「智能分析流水线编排」等长中文产品名称与领域副标题均**单行完整显示、不换行不溢出**。
- **保存产品授权弹窗（Modal 8）消除多余滚动条**：
  - 将原有的普通下拉选择升级为 3×3 可视化产品选择卡片网格，展示中文名、产品标识、摘要说明与核心能力标签；
  - 移除了卡片网格 `max-height: 290px` 强制滚动高度限制，9 大核心产品**一览无余平铺展示**，彻底消除内部多余垂直滚动条。

### 3. 弹窗交互规范化与关闭操作去重 (Modal Close Action Deduplication)
- **移除右上角重复关闭按钮**：
  - 检查并移除了「接入与权限」页面全部 9 个模态弹窗右上角与右下角「取消」按钮功能重复的关闭图标按钮（`modal-close-btn`）；
  - 弹窗统一支持点击遮罩外层（Overlay）及底部明确的「取消」按钮关闭，界面更加整洁统一。
- **修复分配成员弹窗分段控制器宽度不对称**：
  - 修复向当前项目分配成员与角色弹窗中「用户」与「服务账号」分段控制器的宽度自适应与 50%/50% 均匀分配，消除右侧大块空白区域。

### 4. 表格标识列纯净视觉重构 (Clean Monospace ID Cells)
- **清除整列单元格灰色背景**：
  - 优化了 `.muted-id` 样式类，移除了 `background: #f1f4f3` 和内边距，避免将表格中「租户标识」、「项目标识」、「用户标识」、「角色标识」等整列单元格渲染为突兀的灰色块；
  - 保持等宽字体与次级文本颜色展示，使表格整体风格更加清爽、协调与自然。

### 5. 跨浏览器与标准 CSS 兼容性加固 (CSS & Build Robustness)
- **标准 `line-clamp` 兼容性修复**：
  - 修复多处多行文本截断中缺少标准 `line-clamp` CSS 属性的警告，确保在最新现代浏览器与多平台渲染引擎中表现稳健。
