# Scenara 0.3.0-dev.16 发布说明

发布日期：2026-08-10

`0.3.0-dev.16` 拆分人像解析与 OCR 文档解析为独立工作区，完善 OCR 对视频与视频流的帧采样参数体系，修复启动兼容性与 UI 样式缺陷。

## 解析工作区拆分

- **人像解析**与**OCR 文档解析**从合并的单一页面拆分为独立的导航项和工作区视图，侧边栏按领域分组，各自拥有独立路由和工作流。
- 人像领域的数据类型移除文档 (`document`) 标签，仅保留图片 (`image`)、视频 (`video`) 和实时视频流 (`stream`)。
- OCR 文档领域保留图片、视频和实时视频流三种数据类型，支持对视频与视频流中的文档进行帧级 OCR 解析。

## OCR 视频与视频流帧采样参数体系

- 新增 OCR 视频与视频流专属调优参数定义：采样策略 (`interval` / `scene_change`)、采样间隔 (`sample_interval_ms`)、镜头切页阈值 (`scene_change_threshold`)、最大解析帧数上限 (`max_units`)。
- 视频流模式额外支持断线重连次数 (`max_reconnect_attempts`)、连接超时 (`connect_timeout_ms`) 和读取超时 (`read_timeout_ms`) 参数。
- 参数默认值按场景预设：视频默认采样策略为 `scene_change`（画面变动触发），视频流默认为 `interval`（定时采样），可在前端工作区切换后直接调整。

## 启动兼容性修复

- 修复跨版本启动时，内置 Pipeline 定义更新导致 `StateConflict` 异常的问题，允许更新已存在的活跃 Pipeline。
- PostgreSQL State Backend 启动时自动检测并执行未应用的 SQL 迁移文件，避免手动运行迁移脚本。

## 前端样式修复

- 修复全局 CSS 中 `input` 选择器将 `width: 100%` 和 `min-height: 36px` 错误应用到 checkbox/radio 元素的问题，运行页面的"自动刷新"复选框恢复为正常 15×15px 尺寸。
- 为 checkbox 和 radio 统一使用 `accent-color: var(--teal)` 保持主题色一致性。

## 版本与文档同步

- Python 主包、Python SDK、API 系统版本和 Python SDK User-Agent 启用 `0.3.0.dev16`。
- npm 根包、中文 Console、TypeScript SDK、Compose/Kubernetes 镜像和离线包默认标签启用 `0.3.0-dev.16`。
- 更新日志、README、实现矩阵和策略文档同步到新版本。
- 发布门禁改为检查 `docs/release/0.3.0-dev.16发布说明.md`。

1. API、Worker、Console 和离线包统一使用 `0.3.0-dev.16`，不要混用上一版镜像。
2. 首次启动新版本时，PostgreSQL 迁移将自动执行，无需手动操作。
3. 本版本仍是开发资格快照；正式模型制品、固定评估集、目标 GPU、离线安装和法律/签署证据仍受发布门禁约束。
