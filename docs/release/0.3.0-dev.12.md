# Scenara 0.3.0-dev.12 发布说明

发布日期：2026-08-05

`0.3.0-dev.12` 是一次面向安全边界、生产可用性、查询性能、代码拆分和运行目录治理的工程开发快照。它承接 `0.3.0-dev.11` 的中文控制台与配置文档，不代表 `1.0.0` 生产发布；真实模型制品、目标硬件、离线安装、备份恢复、软件许可证和签署证据仍由严格发布门禁失败关闭。

## 版本与兼容性

- Python 主包、Python SDK、API 系统版本和 Python SDK User-Agent 统一为 `0.3.0.dev12`。
- npm 根包、Console、TypeScript SDK、Compose/Kubernetes 镜像和离线包默认标签统一为 `0.3.0-dev.12`。
- 现有 `/api/v1` 路径、审计查询和导出路径保持兼容；新增数据库迁移 `migrations/0011_session_token_index.sql`，升级 PostgreSQL 部署时必须执行迁移。
- 本版本要求生产环境显式启用企业策略并提供企业 license 与公钥文件。没有有效企业策略配置的生产启动会失败关闭。

## 安全与生产可用性

- 修复授权模型的 fail-open 行为：空 `scopes` 不再跳过权限校验，空 `product_ids` 不再意外获得产品访问权。
- API Key 和 Session 在 scope/product 交集被收窄为空时直接拒绝认证，避免降权操作产生提权结果。
- 生产配置强制 `SCENARA_ENTERPRISE_POLICY_REQUIRED=true`，Compose 默认挂载 license 和公钥 secret，未完成企业策略配置的部署不能进入全放行策略。
- Session 认证改用 `token_sha256` 索引查询并使用恒时摘要比较，不再扫描全部租户控制面记录；`last_used_at` 写入按 60 秒节流，并增加运行时过期 Session 清理任务。
- 新增会话摘要索引迁移，Memory/PostgreSQL 控制面实现保持一致，并保留已签发凭据的租户、项目和用户边界。

## 审计与查询性能

- 审计查询下沉到 Memory/PostgreSQL 存储层，支持租户/项目范围内的过滤、排序、`offset/limit` 分页和总数统计，避免将持续增长的审计表全量加载到 Python 内存。
- `/api/v1/audit/export` 改为分页流式 JSON/CSV 导出，不再静默截断为 200 条记录。
- `list_results` 使用批量 Run 查询，消除逐条 `get_run` 的 N+1 往返。
- 结果分片读取改为并发加载并校验 SHA-256；分页结果不再对完整结果对象做深拷贝。
- SSE 连接成功后停止并行轮询，仅在事件流连接失败或完成后回退到轮询，降低单个运行的数据库查询频率。

## 前端与认证体验

- API、表单、Blob 和 SSE 请求统一处理 401：清理失效凭据、广播认证过期事件并回到登录页。
- 认证令牌默认保存在 `sessionStorage`，只有显式选择持久化时才写入 `localStorage`。
- `ParseView` 抽取 `useDomainCatalog` 和 `useMediaPreview` composables，领域清单、Pipeline 参数默认值、媒体资源筛选、媒体预览和对象 URL 回收不再全部堆在单一组件中。
- 保持图片、视频、文档和视频流的原有工作区路由、资源选择、结果加载和历史运行行为。

## 架构与工程化

- 审计 API 拆为独立 `APIRouter`，通过 Runtime、认证依赖和 envelope 回调挂载，保持 OpenAPI 路径与响应结构不变。
- 控制面存储协议和内存实现移至 `scenara/platform/control_plane_store.py`，为后续按 IAM、计费、Flow、Agent、Edge 等域继续拆分提供边界。
- CI 增加同一分支并发取消，避免 push 和 pull request 重复消耗完整流水线；集成服务日志统一写入 `runtime-state/logs/` 后上传 artifact。
- Docker 镜像使用 `COPY --chown`，增加 `/readyz` HEALTHCHECK，减少镜像层和运行时权限漂移。
- 新增 `scripts/prepare_runtime_state.py`，统一初始化本地日志、对象、队列、锁和交付证据目录；rollout 审计默认写入 `runtime-state/logs/rollout-audit.jsonl`。

## 文档与验证

- README、更新日志、实现矩阵、产品矩阵、访问底座、仓库拓扑、人像战略、部署示例和 OpenAPI 版本统一更新到 `0.3.0-dev.12`。
- 新增 runtime-state 布局回归测试，以及授权空 scope/product 场景测试。
- 本次验证：完整 Python 后端测试 `180 passed, 8 skipped`；Console Vitest `19 passed`，typecheck、lint、生产构建、Python Ruff、compileall、OpenAPI 导出校验、开发门禁和实现发布门禁均通过。
- 8 个默认跳过项属于 PostgreSQL/Redis/MinIO 等真实服务集成测试，仍需在 CI 集成服务 job 或本地 Compose 环境执行；完整严格发布门禁继续因未提交法律许可和签署证据而失败关闭。

## 升级步骤

1. 执行 `migrations/0011_session_token_index.sql`，再启动 API、worker 和 scheduler。
2. 为生产环境配置企业 license、公钥和 `SCENARA_ENTERPRISE_POLICY_REQUIRED=true`。
3. 本地开发执行 `python scripts/prepare_runtime_state.py`，确认日志写入 `runtime-state/logs/`。
4. 使用 `0.3.0-dev.12` 镜像标签构建并运行部署门禁；不要把本版本开发快照当作 `1.0.0` 生产资格证明。
