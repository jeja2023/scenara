# Scenara 0.3.0-dev.26 发布说明

`0.3.0-dev.26` 是四仓库规范审计、Data 迁移开发闭环和版本信息同步版本。它补齐 Core 开发兼容 Data 服务的持久化、探针、迁移包导入和跨仓边界，并把独立 Data、Model、Contracts 仓库的实际状态和剩余任务写入责任仓库文档。

## 主要变更

- Core Data 兼容服务支持可选 SQLite 状态日志，Dataset、Version、Sample、Annotation、Quality、Lineage 和 Outbox 可在进程重启后恢复。
- 增加 `/livez`、依赖感知 `/readyz`、Outbox 查询、Manifest、访问授权、Quality Run 和 Lineage Snapshot 接口。
- Hard Sample 接收增加契约版本、租户/项目作用域、SHA-256、授权、脱敏和幂等校验。
- 新增迁移包校验/导入模块和 CLI，校验 manifest/checksums，保留源 ID 和作用域，不访问 Core 数据库。
- 新增 Data PostgreSQL 基线迁移、Compose 状态卷和就绪探针健康检查。
- 新增四仓库符合性审计和 Data/Model/Contracts 责任仓库剩余任务计划。
- Model `pyright` 绑定 `.venv`，保证 ONNX/Alembic 开发依赖能够被类型检查器解析。
- 发布兼容性契约 `@scenara/repository-contracts` `1.0.1`，保留 `v1.0.0` 历史目录和摘要不可变。
