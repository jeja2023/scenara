# Scenara 0.3.0-dev.28 发布说明

`0.3.0-dev.28` 完成 OCR、Behavior、Fashion 多领域开发链路的四仓库契约收口。该版本仍是开发版；领域代码存在不代表模型已经获得生产资格。

## 主要变更

- Core 注册 Behavior 与 Fashion 领域插件，并为 OCR、Behavior、Fashion 提供强类型结果负载。
- 消费 `@scenara/repository-contracts` `1.1.0`，增加领域标注模式、多领域反馈类型、领域元数据和多文件模型制品清单。
- OpenAPI、Python/TypeScript SDK、Console、Compose、Kubernetes 与离线包统一为 `0.3.0-dev.28`。
- Behavior、Fashion、OCR 内置参考适配器明确标记为 `unqualified_reference_adapter`，不再仅凭类名或代码存在声明生产就绪。
- 严格发布门禁增加 `behavior_evaluation` 与 `fashion_evaluation`，两者必须使用固定、权利已清理的数据集完成至少两次可复现运行。

## 生产停止条件

- 禁止使用占位模型摘要、随机输出或启发式回退作为生产推理结果。
- 模型必须由 `scenara-model` 产出不可变制品清单、模型卡和评估证据，并在 Core 完成准入、激活和运行时健康检查。
- Data 必须校验已发布的领域标注模式并提供不可变 Dataset Version。
- Behavior、Fashion、OCR 的模型权属、固定评估集、GPU 容量和离线安装证据未齐全时，严格发布门禁必须失败。
