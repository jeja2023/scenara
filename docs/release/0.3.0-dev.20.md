# Scenara 0.3.0-dev.20 发布说明

**发布日期**：2026-08-13

`0.3.0-dev.20` 完成了 OpenAPI 接口规范瘦身清理、Redis 队列自愈机制与控制面状态校验工具、自动化发布佐证打标与验证工具，以及 Console 解析工作区的采样结果帧预览与标注叠加优化。

---

## 主要变更

### 1. OpenAPI 规范瘦身与旧版接口清理

- 弃用并从 OpenAPI 描述中隐藏旧版企业级接口（如 `/api/v1/enterprise/*` 及计费席位、计量相关接口），统一标记为 `Legacy` 并且 `include_in_schema=False`。
- 将配额方案与配额检查接口（Quota Plans / Check）调整至 `Operations` 标签组。
- 简化系统状态响应字段 `policy_provider`，导出的 `docs/openapi.json` 由 11,200 余行精简至 6,700 余行，显著降低 TypeScript SDK 构建产物与客户端请求体积。

### 2. Redis 队列自愈与状态重建

- 新增 `scenara/queue_recovery.py` 核心自愈模块与 `scripts/rebuild_redis_queue.py` 命令行运维工具。
- 支持直接从 PostgreSQL / Control Plane 持久化状态中提取所有可恢复的 Run 任务，并对关联的数据资产（`MediaAsset`）、媒体源（`MediaSource`）以及对象存储（ObjectStore / MinIO）文件进行存在性与完整性校验。
- 在 Redis 缓存数据丢失、崩溃或队列死锁时，可通过单条命令无损恢复 Redis Run 队列，避免在途任务丢失。

### 3. 自动化发布佐证打标与集成测试

- 新增 `scripts/prepare_release_evidence.py` 与 `scripts/record_release_evidence.py` 脚本，实现发布佐证目录结构自动初始化、软件许可证校验以及凭证清单（Manifest）签名生成。
- 扩充 `scripts/release_gate.py` 发布门禁与 `tests/test_release_gate.py`、`test_prepare_release_evidence.py`、`test_record_release_evidence.py` 自动化测试，确保发布佐证打标全流程可靠。

### 4. Console 解析工作区结果帧预览与交互优化

- **结果帧智能降级与缓存**：在 Console 解析工作区（`ParseView.vue`）中，当浏览器无法播放视频文件、或处于文档/实时流模式时，自动加载与当前选择采样单元对应的服务端结果帧（Result Frame），并引入轻量缓存机制提升切换流畅度。
- **标注画框精准定位**：同步结果帧与 Canvas Bounding Box 标注叠加画框，新增“正在加载结果帧 / 同步中”状态提示面板，避免定位未完成时的框选错位或空白遮挡。
- **视图组件瘦身**：彻底移除废弃的 `EnterpriseWorkspaceView.vue` 组件及其路由与导航配置，保持前端代码库干净精简。

## 升级与兼容性说明

1. OpenAPI 隐藏的旧版企业接口与计费接口在后端仍保留逻辑适配，但不再推荐在新集成中使用；新集成请统一使用全新的 Operations 与 Platform 控制面 API。
2. 在 Redis 遭遇异常掉电或队列清空时，可执行 `python scripts/rebuild_redis_queue.py` 完成队列自动自愈与数据校验。
3. 镜像、Compose、Kubernetes 与离线部署的默认标签升级为 `0.3.0-dev.20`。
