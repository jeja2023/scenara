# Scenara 0.3.0-dev.30 发布说明

`0.3.0-dev.30` 聚焦于前端控制台全站数据表格的工程化重构与视觉规范标准化。通过构建通用声明式表格组件体系，彻底解决空数据状态下表格单元格坍塌与文字垂直挤压折行问题，实现了全系统数据表格在序号列、边框线、对齐规则、分页控制与标题布局上的全局统一。

## 主要成果

### 1. 通用数据表格组件体系
- **数据表格组件** ([frontend/console/src/components/DataTable.vue](file:///d:/project/scenara/frontend/console/src/components/DataTable.vue))：
  - **声明式配置**：通过 `columns: TableColumn<T>[]` 定义列标识、标题、宽度、对齐方式与自定义 class。
  - **自动序号与跨列计算**：默认开启 50px 固定宽度的居中序号列（并支持 `indexOffset` 分页自动递增）；空状态与加载状态自动根据实际列数精准计算 `colspan`，彻底杜绝跨列错位和字符挤压折行。
  - **完善的插槽能力**：提供单元格插槽 `#[column.key]="{ row, value, index, actualIndex }"`、表头插槽、展开子行 `#subrow="{ row, totalColspan }"` 与自定义空状态插槽 `#empty`。
  - **内置分页集成**：深度无缝集成 `DataTablePagination`。
- **分页控制组件** ([frontend/console/src/components/DataTablePagination.vue](file:///d:/project/scenara/frontend/console/src/components/DataTablePagination.vue))：
  - 统一规范“显示第 X-Y 条，共 N 条记录”统计、翻页按钮与当前页码指示器。
- **全局类型导出** ([frontend/console/src/types.ts](file:///d:/project/scenara/frontend/console/src/types.ts))：导出强类型 `TableColumn<T>` 定义。

### 2. 空数据渲染异常修复与布局优化
- **CSS 属性隔离** ([frontend/console/src/styles.css](file:///d:/project/scenara/frontend/console/src/styles.css))：
  - 修正通用 `.empty` 样式规则，避免 `display: grid` 覆盖 `<td>` 的 `display: table-cell` 造成浏览器表格渲染引擎忽略 `colspan` 属性。
  - 修复解析工作台（行为识别、服装识别、人像识别等）在无历史数据时提示文字被 50px 宽度强制逐字折行下坠的问题。
- **标题与工具栏横向布局** ([frontend/console/src/views/ParseView.vue](file:///d:/project/scenara/frontend/console/src/views/ParseView.vue))：
  - 运行历史面板左侧主标题与领域说明文字（如 `OCR 文档 最近运行记录`）改为横向基线对齐。
  - 运行历史面板右侧「刷新」与「查看全部」操作按钮改为横向紧凑排列，消除垂直折行堆叠。

### 3. 全站数据表格全面重构与接入
全站 12 个视图与组件的 18 处数据表格统一重构为 `<DataTable>`：
- `ParseView.vue`：解析工作台最近运行记录与目标检测边框表。
- `RunsView.vue`：全局运行历史队列与状态流转。
- `ResultsView.vue`：解析成果综合检索列表与详情联动。
- `AuditView.vue`：安全审计日志列表与导出。
- `OverviewView.vue`：核心算法能力清单与最近运行动态。
- `MediaView.vue`：媒体资产清单（带多选与元数据展开子行）与 RTSP 视频流源清单。
- `FeedbackView.vue`：反馈队列、难例清单、模型发布版本与部署事件记录。
- `PipelinesView.vue`、`ModelsView.vue`、`OperationsView.vue`、`GovernanceView.vue` 与 `GenericDomainResult.vue`。
