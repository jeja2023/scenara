# Scenara 0.3.0-dev.35 发布说明

`0.3.0-dev.35` 重点聚焦于**人像解析全量检出与零截断限制解除**、**服饰风格识别增强（二次元 Cosplay 战袍与洛丽塔精准分类）**、**全平台数据表格通用分页控件与每页条数限制支持**，以及**跨镜长期轨迹系统深度检验与专属快速冒烟测试套件**。

## 主要成果

### 1. 人像解析全量检出与零截断限制解除
- **移除硬编码检测上限截断** ([scenara/domains/portrait/operators.py](file:///d:/project/scenara/scenara/domains/portrait/operators.py), [app/inference_detection.py](file:///d:/project/scenara/app/inference_detection.py))：
  - 彻底移除了人像分析在检测框后处理阶段历史遗留的 `MAX_DETECTIONS = 64` / `MAX_TRACKLETS = 64` 硬编码截断限制；
  - 算法全面升级为动态可配置检测上限（默认最大支持单帧 1000+ 个人员全量无损检出），解决密集人流、大型集会或远景画面中由于数量阈值导致部分人体未被框选漏检的问题；
  - 在后处理、多人员追踪与人体/人脸特征提取链路（[app/postprocess.py](file:///d:/project/scenara/app/postprocess.py), [app/runtime_body.py](file:///d:/project/scenara/app/runtime_body.py), [app/runtime_face.py](file:///d:/project/scenara/app/runtime_face.py)）中全链路打通无限制高并发检测。

### 2. 服饰风格识别增强与二次元 Cosplay / 洛丽塔精准识别
- **二次元角色与战袍精准召回** ([scenara/domains/fashion/operators.py](file:///d:/project/scenara/scenara/domains/fashion/operators.py))：
  - 增强了二次元角色、ACG 战袍、洛丽塔等小众风格的检测召回率，支持暗黑系战袍、深发色 ACG 角色（如黑发战袍、铠甲披风、短裙佩刀）与洛丽塔裙装（Lolita White Dress）；
  - 优化了色彩直方图、边缘纹理与特征加权算法，同时引入负样本对比防护机制，严格保护日常休闲通勤服饰（Polo 衫、普通黑色外套配牛仔裤、白T恤配黑色短裤等），防止误判为战袍；
  - 实现了多风格精准分类：Cosplay（二次元战袍/角色）、Lolita（洛丽塔）、Hanfu（汉服/国风）、JK（JK制服）、Gothic（哥特风）、Qipao（旗袍）、Techwear（机能风）等。

### 3. 数据表格通用分页控件与每页条数限制支持
- **分页器组件升级** ([frontend/console/src/components/DataTablePagination.vue](file:///d:/project/scenara/frontend/console/src/components/DataTablePagination.vue))：
  - 新增**每页条数自选下拉菜单**（支持 10/20/50/100 条/页，切换时自动重置至第 1 页）；
  - 新增**高光数字页码按钮**与智能省略导航（如 `1 2 3 ... 10`）；
  - 新增**快速输入跳页**输入框（`跳至 [X] 页`）。
- **通用数据表格客户端内存切片与服务端分页** ([frontend/console/src/components/DataTable.vue](file:///d:/project/scenara/frontend/console/src/components/DataTable.vue))：
  - 支持**开箱即用的自动客户端内存切片分页**（当传入前端纯数组未传入异步 `total` 时，内部按 `localOffset` 与 `localPageSize` 自动做 `slice` 切片）；
  - 当传入的数据数组 `items` 发生变化时，自动平滑重置至第 1 页；
  - 保持与服务端异步分页的兼容性，双向派发 `update:pageSize` 与 `pageSizeChange` 事件。
- **业务页面全量落地**：
  - 在当前单元目标明细表（[ResultDetailDrawer.vue](file:///d:/project/scenara/frontend/console/src/components/ResultDetailDrawer.vue)）、通用领域结构化扩展表（[GenericDomainResult.vue](file:///d:/project/scenara/frontend/console/src/components/GenericDomainResult.vue)）、解析结果列表（[ResultsView.vue](file:///d:/project/scenara/frontend/console/src/views/ResultsView.vue)）、任务运行列表（[RunsView.vue](file:///d:/project/scenara/frontend/console/src/views/RunsView.vue)）中全量应用。

### 4. 跨镜头长期轨迹深入检查与专属快速冒烟测试套件
- **跨镜轨迹追踪与时空拓扑深度检验** ([scenara/domains/portrait/trajectory.py](file:///d:/project/scenara/scenara/domains/portrait/trajectory.py))：
  - 深度审查并验证了跨镜头多模态 Re-ID 融合（OSNet 人体 55% + ArcFace 人脸 45% 加权）、时空拓扑约束（最小/最大物理耗时瞬移阻断）、同帧防自碰撞排他、32个动态模板池 LRU 衰减淘汰，以及身份合并（Merge）/片段拆分（Split）治理全流程；
  - 新增了长期轨迹专属快速端到端冒烟测试脚本 [scripts/test_trajectory_quick.py](file:///d:/project/scenara/scripts/test_trajectory_quick.py)；
  - 平台 82 项自动化测试（`pytest`）及 25 项长期轨迹专项测试 100% 通过。
