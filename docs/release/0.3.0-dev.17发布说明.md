# Scenara 0.3.0-dev.17 发布说明

发布日期：2026-08-10

`0.3.0-dev.17` 优化总览与解析工作区布局、为全平台前端所有数据表格补齐带单元格边框与 `序号` 列、重构左侧导航栏分组与高频布局。

## 数据表格单元格边框与序号列全覆盖

- 为全平台前端控制台 `Console` 所有的 20+ 个数据表格统一引入显式单元格边框样式（`bordered-table`），并为所有的 `<thead>` 与 `<tbody>` 数据项新增第一列 **`序号`**。
- 覆盖页面与组件包括：`OverviewView.vue`（仓库拓扑、能力就绪度、最近运行）、`RunsView.vue`（运行队列）、`ParseView.vue`（识别对象明细）、`MediaView.vue`（文件资产表、视频流源表）、`PipelinesView.vue`（流水线列表）、`ModelsView.vue`（模型管理表）、`GovernanceView.vue`（平台生命周期、计费用量）、`FeedbackView.vue`（反馈审核、难例清单、模型发布、部署事件）、`EnterpriseWorkspaceView.vue`（权益用量、事件记录）、`AuditView.vue`（审计事件表）、`AccessView.vue`（用户列表、服务账号、API 密钥、产品授权、事件回调订阅、最近投递）及 `GenericDomainResult.vue`（通用数据表）。

## 总览与解析工作区布局重构

- **总览页面（Overview）**：重构产品矩阵卡片、人像智能核心能力大卡片、依赖架构与数据表格视觉层级，显式强化边框与暗色极简态势感知。
- **人像与 OCR 解析工作区（ParseView）**：移除左上角重复冗余标题与二级工具栏，将页面操作链接收归整合至顶部统一的 `workbench-config` 栏；优化媒体展示区域、结构化对象结果计数、属性网格与时序解析项面板。

## 左侧导航栏结构与垂直高度优化

- **5 大核心功能域分组重构**：
  - **核心工作区**：总览、人像解析、OCR 文档解析、运行历史
  - **数据与分析**：解析结果、数据资产、数据集治理
  - **智能检索**：综合检索、人像比对、长期轨迹
  - **AI 引擎与模型**：领域与能力、流水线、模型管理、反馈与发布
  - **平台治理与系统**：接入与权限、平台治理、审计中心、系统运维、企业专区
- **垂直高度与无痕滚动条优化**：左侧 Branding 栏高度调至 `58px` 与 Header 对齐；菜单项高度调整为 `30px`、间距压缩至 `1px`，在常用 1080p/768p 屏幕下实现整屏展示不触发滚动条；补充 `4px` 极细暗色自定义滚动条支持。
