# Scenara 0.3.0-dev.18 发布说明

**发布日期**：2026-08-10

`0.3.0-dev.18` 统一顶部 Header 刷新按钮与 Hook，优化人像解析与 OCR 文档解析动态顶栏标题，重构解析工作区按钮布局与分段样式。

---

## 主要变更

### 1. 全局 Header 统一刷新按钮与 Hook
- **顶部顶栏统一刷新**：在控制台 Header 右侧 `topbar-actions` 区域内，在“已连接”状态指示按钮左侧新增统一刷新按钮。点击时触发全局 `scenara:refresh` 事件，并展示 Icon 旋转动画。
- **通用 `useRefresh` Hook**：新增 `frontend/console/src/composables/useRefresh.ts`，方便视图页面订阅顶部刷新事件，并在组件卸载时自动解绑。
- **视图页面瘦身**：优化 Console 18 个视图页面（Overview, Parse, Media, Results, Runs, Search, Capabilities, Pipelines, Models, Access, Governance, Dataset, Enterprise, Feedback, Operations, PortraitCompare, Trajectory, Audit），移除各页面顶部重复的“刷新”按钮，统一由顶栏刷新触发。

### 2. 领域解析顶栏动态标题与描述
- **标题精准化**：修复此前访问人像解析（`/parse/portrait`）和 OCR 文档解析（`/parse/ocr`）及其媒体子路径（如 `/parse/portrait/image`、`/parse/ocr/document`）时，左上角顶栏标题默认显示为通用“解析”的问题。
- **描述同步关联**：访问人像解析时顶部显示 **人像解析**（描述：*检测人员并分析人像相关的视觉特征。*）；访问 OCR 文档解析时顶部显示 **OCR 文档解析**（描述：*识别并分析文档中的文字、结构和关键信息。*）。
- **网页 Tab 标题更新**：浏览器标签页 `document.title` 同步显示对应领域名称。

### 3. 解析工作区按钮布局与工作区样式重构
- **“开始解析”下沉与对齐**：在 `ParseView.vue` 工作区中，将主要操作按钮“开始解析”下沉移至解析控制栏（流水线下拉框右侧），放置在“查看历史运行”链接按钮左侧，形成更符合直觉的流式配置与执行体验。
- **运行历史领域联动**：点击“查看历史运行”时携带当前领域 query 参数（如 `/runs?domain=portrait`），`RunsView` 自动加载并预筛选对应领域的历史运行记录。
- **去处顶部分割线**：移除解析工作区顶部冗余的横线 border；顶部 `page-header` 仅在存在运行状态动作（如暂停、恢复、取消）或结果导出（JSON/CSV）时渲染。

### 4. 工程与版本对齐
- Python 主包、Python SDK、API 系统版本和 User-Agent 统一启用 `0.3.0.dev18`。
- npm 根包、中文 Console、TypeScript SDK、Compose/Kubernetes 镜像和离线包默认标签启用 `0.3.0-dev.18`。
- 发布门禁更新为检查 `docs/release/0.3.0-dev.18发布说明.md`。
