# Scenara 0.3.0-dev.41 发布说明

`0.3.0-dev.41` 是 `0.3.0-dev.40` 之后的控制台视觉设计紧凑化、控件规范统一与模型类型筛选重构版本。本版本不改变公开 API 路径与数据契约，重点优化全站交互体验、数据密度与统一视觉规范。

## 主要变更

### 全局控件与输入体系紧凑化

- **标准按钮与搜索框规范**（`styles.css`）：
  - 标准按钮 `.button, a.button` 高度由 `34px` 优化为紧凑标准的 **`26px`**（字号 `11.5px`）；
  - 小按钮 `.tiny-btn, .button.sm, .button.btn-sm` 高度统一为 **`22px`**（字号 `11px`）；
  - 搜索框 `.search-box` 默认高度由 `28px` 紧凑至 **`24px`**，小号搜索框 `.search-sm` 紧凑至 **`22px`**。
- **全局工具栏与筛选器**（`.filter-controls`）：
  - 制定全局统一的 `.filter-controls` 规范，内边距统一为 `4px 10px`；
  - 下拉框 `.filter-select` 与日期时间输入框 `.date-input` 高度统一为 **`22px`**（`line-height: 20px`），字号 `11px`。
- **全局分页控件**（`DataTablePagination.vue`）：
  - 每页条数下拉选择框（`20 条/页`）与快速跳页输入框尺寸全面紧凑化至 **`22px`** 高度与 `11px` 字号。

### 业务视图深度精细化

- **人像检索与相似度阈值**（`SearchView.vue`）：
  - 相似度阈值输入框（`.threshold-field`）与卡片右侧容器（`.portrait-threshold-box`）收缩为精致紧凑的 **`22px`** 高度与 **`56px`** 居中宽度，去除默认数值微调按钮的过宽占用；
  - 人像特征上传与资产选择框高度调整为 `24px`，特征缩略图框收紧为 `52px`。
- **人像比对**（`PortraitCompareView.vue`）：
  - 比对阈值输入框高度收缩至 `22px`，快速阈值胶囊药丸（`0.70/0.80/0.85`）高度统一至 `22px`。
- **轨迹分析**（`TrajectoryView.vue`）：
  - 状态、机位下拉筛选框及起止时间选择器高度统一至 `22px`，优化排版密度。
- **数据集治理**（`DatasetView.vue`）：
  - 侧边栏状态下拉框（`.sidebar-status-select`）紧凑至 `22px` 高度与最大宽度限制，修复 W3C 标准 `line-clamp` 兼容性告警。
- **模型管理**（`ModelsView.vue`）：
  - 将原先占位过宽的 Tab 按钮组重构为带有图标标签的 **`模型类型:` 下拉筛选框（`.filter-select`）**，与右侧紧凑搜索框视觉对齐。
