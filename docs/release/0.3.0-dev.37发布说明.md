# Scenara 0.3.0-dev.37 发布说明

`0.3.0-dev.37` 重点聚焦于**控制台全站界面体验优化与视觉一致性升级**、**布控预警系统全面中文化与去重重构**、**数据资产过滤搜索与 Tab 分段视图标准化**，以及**全局分页组件稳固性治理**。

## 主要成果

### 1. 顶栏精简与全屏空间扩展 (Topbar Optimization & Full-width Expansion)
- **顶栏产品标识清理**：移除了顶部导航栏各页面左侧冗余的“视觉 AI 中枢平台”文字徽标与分隔线，让界面更清爽聚焦；
- **全屏工作区宽度释放**：清理并移除了页面左右两侧的历史边距限制，解除 `max-width` 约束，将 `.page`、`.search-page`、`.results-page` 容器宽度扩展为 100%，大幅释放横向空间，显著提升表格与多媒体视图的有效操作视野。

### 2. 布控预警系统全面中文化与去重重构 (Surveillance Subsystem Localization & Layout Polish)
- **全面前端 UI 中文化**：
  - 针对布控预警（实时预警中心、告警研判、布控任务、布控名单）完成前端 UI 界面深度中文化；
  - 在 `labels.ts` 中补齐了告警研判状态（待处置/已确认/误报/已忽略）、任务状态（草稿/运行中/已暂停/已停止/已归档）、名单类别（黑名单/白名单/自定义）、名单状态（已启用/已停用）与模态类型的中文映射。
- **页面标题去重与就近工具栏整合**：
  - 移除了布控预警各子页面内 Tab 导航下方与顶部页面标题重复的标题名称与注释说明；
  - 实时预警页面的连接状态与静音控制工具栏优化为紧凑右对齐；告警研判、布控任务与布控名单页面的“刷新”按钮统一就近整合至筛选栏与列表面板头部。
- **Tab 导航全局统一样式**：
  - 重构了 `SurveillanceLayout.vue` 的 Tab 导航，移除了原来突兀的独立外框卡片与投影，采用全局标准的嵌入式分段 Tab 栏（浅灰底色 `#eef2f1`、轻量圆角 `6px`、标准图标尺寸 `13px`）。

### 3. 全局切换按钮（Tab / Segmented）选中态视觉统一 (Unified Tab & Switch Active State)
- **淡绿高亮风格统一**：
  - 参照布控预警页面的选中高亮样式，将全站所有页面切换按钮选中的白色背景（`#ffffff`）统一替换为淡绿色高亮背景（`var(--color-accent-soft, #e4f1f1)`）与深青/绿文字（`var(--color-accent-hover, #065e67)`）；
  - 统一覆盖了多模态解析工作区（能力模式、数据类型、上传来源）、综合检索模式切换（文搜图/人搜图）、总览多维矩阵切换、模型引擎领域切换、用户反馈领域切换、权限治理领域切换、结果详情抽屉 OCR Tab 等。

### 4. 数据资产页面 UI 重构与 Tab 分段隔离 (Media Assets & Streams Refactoring)
- **文件资产过滤搜索标准化**：
  - 彻底废弃文件资产原有的多组分段按钮，改用全局统一的 `<div class="filter-controls">` 过滤搜索栏；
  - 配备漏斗图标“筛选记录”标识、领域下拉选择框（全部领域/服饰风格/人像解析/行为分析/文字识别）、类型下拉选择框（全部类型/图片/视频/文档）与一键重置按钮，并保留匹配数量与文件总容量统计。
- **双资产 Tab 页面切换展示**：
  - 在“数据资产”页面顶部新增全局统一样式的 Tab 切换导航（“文件资产”与“视频流源”，附带数量角标）；
  - 将垂直堆叠的两大面板解耦为独立 Tab 页面，彻底解决长页面上下翻动问题。

### 5. 全局分页控件换行与尺寸溢出治理 (Pagination Stability & Layout Fixes)
- **防文本折行加固**：
  - 为 `DataTablePagination.vue` 与全局 `styles.css` 中的 `.pagination-jumper`、`.jumper-label` 和 `.pagination-controls` 增加 `white-space: nowrap` 与 `flex-shrink: 0` 规则，防止“跳至”等中文文本在小屏或窄容器下发生异常换行。
- **输入框尺寸隔离与溢出防护**：
  - 隔离了全局通用输入框样式对分页跳页输入框的样式污染，精确固定 `.pagination-jumper-input` 尺寸为 `40px x 24px`、行高 `22px`、内边距 `0 4px`；
  - 隐藏数字输入框自带的上下微调箭头（Spinner），确保跳页输入框在任何屏幕宽度下均保持紧凑精致且不溢出分页容器。
