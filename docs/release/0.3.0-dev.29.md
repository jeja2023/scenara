# Scenara 0.3.0-dev.29 发布说明

`0.3.0-dev.29` 按产品级生产环境要求完成全面加固，默认失败关闭，且未生成或写入任何真实凭据。该版本通过自动化工具、Compose 与 Kubernetes 规范以及运行时防御机制，构建起完整的生产安全基线。

## 主要成果

### 1. 安全生产配置生成器与校验器
- **配置生成器** ([scripts/generate_production_env.py](file:///d:/project/scenara/scripts/generate_production_env.py))：提供一键生成生产安全环境配置能力，自动生成符合密码学强度的强随机密码与 Fernet 密钥，消除弱凭据风险。
- **配置校验器** ([scripts/validate_production_config.py](file:///d:/project/scenara/scripts/validate_production_config.py))：在服务启动前对生产配置进行严格的 Preflight 校验，覆盖密码强度、端口绑定、Host 白名单、HTTPS 与模型适配器配置，失败立即退出。
- **完善生产模板** ([deploy/.env.production.example](file:///d:/project/scenara/deploy/.env.production.example))：全面规范中文注释与分块结构，对齐所有生产变量要求。

### 2. Docker Compose 生产加固 ([deploy/compose.yml](file:///d:/project/scenara/deploy/compose.yml))
- **认证强化**：启用 Redis 密码认证，MinIO 根账号（Root User）与应用 S3 业务账号严格分离。
- **安全容器上下文**：全量容器启用只读根文件系统（`read_only: true`）、以非 root 用户（UID `10001:10001`）运行、删除全部 Linux Capabilities（`cap_drop: [ALL]`）、禁止权限提升（`no-new-privileges: true`）。
- **网络与资源隔离**：引入隔离的内部后端网络（`scenara-internal`），配置 CPU/内存限制（Resource Limits）、PID 上限保护与 JSON 日志轮换（Log Rotation）。
- **回环监听**：API 服务默认仅监听本地回环地址 `127.0.0.1`，必须通过反向代理对外提供服务。
- **启动预检**：容器启动前自动执行配置 preflight 校验，防止错误配置上线。

### 3. Kubernetes 生产加固
- **安全上下文**：Pod 与容器级别配置非 root、Seccomp RuntimeDefault 配置文件、只读文件系统、禁止特权提升。
- **资源保障与高可用**：设置 GPU 资源配额、模型只读 PVC（`ReadOnlyMany`）、PodDisruptionBudget（PDB）与拓扑分布约束（`topologySpreadConstraints`）。
- **调度与隔离**：包含独立 Scheduler、独立迁移 Job（`migrate-job.yaml`）以及默认拒绝所有未授权进出流量的 NetworkPolicy。
- **Ingress 示例** ([deploy/kubernetes/ingress.example.yaml](file:///d:/project/scenara/deploy/kubernetes/ingress.example.yaml))：提供符合生产 TLS、超时和 SSE 规范的 Ingress 路由示例。

### 4. 镜像固定与反向代理入口
- **基础镜像固定**：所有 Dockerfile 基础镜像及依赖镜像全部严格固定至不可变的 SHA-256 digest。
- **Nginx 模板** ([deploy/reverse-proxy/nginx.conf.example](file:///d:/project/scenara/deploy/reverse-proxy/nginx.conf.example))：新增专用的 Nginx 反向代理配置模板，预置 TLS 1.3、安全响应头、HTTP/2 及对 SSE 长连接流式输出的缓冲与超时优化。
- **上线检查清单** ([deploy/PRODUCTION_CHECKLIST.md](file:///d:/project/scenara/deploy/PRODUCTION_CHECKLIST.md))：提供覆盖配置、证书、备份、权限与监控的完整生产上线 Checklist。

### 5. 运行时防御与通信安全
- **请求安全**：API 运行时增加 Host 白名单防御、HSTS 严格传输安全、安全响应头（CSP、X-Frame-Options、X-Content-Type-Options）。
- **机密与通信校验**：强制强凭据长度校验、独立信任 Token 验证、Fernet 密钥格式检验以及外部依赖服务的 HTTPS 协议强制校验。
