# Scenara 0.3.0-dev.24 发布说明

**发布日期**：2026-08-20

`0.3.0-dev.24` 是 `0.3.0-dev.23` 之后的契约与工程治理开发快照，依据《景枢平台总体开发规范》完成事件信封、结构化可观测性、公共错误码、Data 平台边界类型、Console 设计令牌和全栈回归门禁整改。独立 `scenara-data` 服务及目标环境资格证据仍不属于本仓库，必须按切流与严格发布门禁独立交付和验收。

---

## 主要变更

### 1. 事件与 API 契约

- `RunRecord` 保存请求 ID 和追踪 ID，`RunEvent` 增加 `event_version`、`occurred_at`、`producer`、租户/项目、请求和追踪字段。
- Run SSE 事件与 Webhook 投递统一使用版本化事件信封，签名覆盖完整信封内容；内存和 PostgreSQL 出站队列均在边界补齐默认上下文字段。
- 重新导出 `docs/openapi.json`，重新生成 TypeScript SDK 源码和 `dist` 制品，避免公共契约与客户端漂移。

### 2. 可观测性与错误处理

- API 请求校验或生成 W3C `traceparent`，规范化 `X-Request-Id` 并向下游 `PrincipalContext` 传递。
- JSON 日志固定包含 UTC RFC3339 `timestamp`、`level`、`service`、`module`、`request_id`、`trace_id` 和 `message`，可附带 `traceparent`、租户及异常信息。
- 新增显式公共错误码目录；未知错误码统一映射为 `INTERNAL_SERVER_ERROR`，内部异常响应使用通用消息。

### 3. Data 平台与迁移边界

- 远程 Annotation、Dataset、Dataset Version DTO 进行严格字段、状态枚举和数值类型收窄，并保留 Data `ready`/`archived` 到 Core `validated`/`retired` 的兼容映射。
- 迁移导出器支持带时区的 RFC3339 字符串时间，并统一输出 UTC `Z`；无时区时间会在边界拒绝。

### 4. Console 与质量门禁

- 新增表头、选中态、遮罩语义令牌，收敛媒体、结果和运行视图硬编码颜色。
- 移动端关键按钮、选择器和图标控件满足 44px 触控目标；更新 RTSP 接口术语与 Data 仓库生命周期模拟。
- 增加事件信封、Webhook、公共错误码和 SSE 契约回归覆盖，并新增公共时间/事件迁移 ADR。

## 升级说明

1. Webhook 和 SSE 消费方应忽略未知信封字段，并使用 `event_version` 进行兼容判断；事件仍按至少一次投递处理并以 `event_id` 去重。
2. `0.3.x` 资源 DTO 的 Unix 秒时间字段保持兼容；新事件使用 RFC3339 `occurred_at`。完整迁移边界见 [ADR 0005](../adr/0005-public-time-and-event-contract-migration.md)。
3. 重新生成或升级 SDK 后，调用方可读取 Run 的 `request_id`、`trace_id` 及事件追踪字段。
4. Compose、Kubernetes 和离线包默认镜像标签已切换为 `0.3.0-dev.24`，可继续使用 `SCENARA_IMAGE_TAG` 覆盖。

## 已知限制

- 严格发布门禁仍要求重新绑定当前 OpenAPI 摘要；既有发布证据不能直接复用于新契约。
- `gpu_capacity`、`model_rights`、`ocr_evaluation`、`offline_install`、`portrait_evaluation` 仍需目标环境的真实、可复现证据，当前版本不宣称生产资格已完成。
