# Scenara 0.3.0-dev.34 发布说明

`0.3.0-dev.34` 重点聚焦于 OCR 分层合规审查与企业级风控词库体系、解析工作台深度布局重构与极简交互优化（包括移除视频下方多余面板、布尔参数纯药丸化、所有参数默认直展、文档核心参数三列同行、语言提示下拉选择化、选择文件按钮质感优化与资产库默认不选中治理）。

## 主要成果

### 1. OCR 分层合规审查与企业级风控词库体系
- **合规检测引擎与分层判定** ([scenara/domains/ocr/compliance.py](file:///d:/project/scenara/scenara/domains/ocr/compliance.py))：
  - 深度重构 OCR 文本合规性检测逻辑，内置《广告法》绝对化极限词、涉政违规、虚假承诺与诱导欺诈等合规红线；
  - 增加**自定义敏感词**（`custom_sensitive_words`）与**合规豁免白名单**（`compliance_whitelist`）动态配置通道，支持通过流水线领域参数实时下发或挂载本地 `data/compliance/custom_sensitive_words.json`；
  - 实现白名单优先放行判定机制（如“第一人民医院”、“第一分公司”、“国家级风景名胜区”等合法机构名精确豁免报错），杜绝合法词汇被极限词误杀；
  - 违规事件支持严重程度分级管控（`block` 违规阻断、`warning` 风险警告、`info` 合规提示），并随分析结果返回精准法条参考依据与修改建议。

### 2. 多模态解析工作台深度布局重构与极简化
- **消除冗余面板与操作混淆** ([frontend/console/src/views/ParseView.vue](file:///d:/project/scenara/frontend/console/src/views/ParseView.vue))：
  - 彻底移除视频播放画板下方的额外指标面板与多余的“开始解析”按钮，全工作台统一保留右上角唯一的全局 `[ 开始解析 ]` 主操作入口，界面整洁聚焦。
- **领域布尔参数纯色块标签化**：
  - 将原 Checkbox 复选框方案重构为现代语义化纯轻量药丸胶囊按钮（Pill Button），彻底移除方块勾选框 `[✓]`；
  - 未选中为中性浅灰，选中即通体高亮翡翠绿（`#ecfdf5` + `#10b981`），点击交互灵动高级且全工作台通用生效。
- **取消参数折叠功能，默认直接平铺展开**：
  - 彻底移除所有“展开/收起高级参数”折叠切换按钮，采样参数与领域配置均平铺直展，免除二次点击展开的操作成本。
- **文档解析核心参数三列同行排布**：
  - 采用动态三列栅格（`cols-3`），将 `最大页数`（100）、`最低置信度`（0.5）与 `语言提示` 紧凑对齐在首行同一行；长文本项 `合规豁免白名单` 与 `自定义敏感词` 跨满整行（`parameter-wide`）；图片/视频模式下自适应为双列并排（`cols-2`）。
- **语言提示升级为标准下拉选择框（Select）**：
  - 彻底免去手动敲击 `zh`、`en` 等简码的认知负担，内置中英通用 (zh)、英文 (en)、日文 (ja)、韩文 (ko)、繁体中文 (cht)、法语 (fr)、德语 (de)、俄语 (ru)、西班牙语 (es) 等标准语言选项。
- **OCR 介质标签顺序规范化**：
  - 调整为符合业务工作流的标准顺序：**`[ 图片 ]` $\rightarrow$ `[ 文档 ]` $\rightarrow$ `[ 视频 ]` $\rightarrow$ `[ 视频流 ]`**，并在插件清单中同步更新。
- **选择文件按钮质感优化**：
  - 在严格保持原有紧凑规格尺寸（`26px` 高度）前提下，针对 `::file-selector-button` 重设现代圆角微投影与翡翠绿悬停交互，消除原生浏览器粗糙灰色斜面边框；去除未选中时的冗余文字，已选文件优雅展示绿色文件大小提示。
- **资产库刷新与页面切换默认不选中**：
  - 页面刷新（F5）或切换页面（路由/领域/介质变更）后，资产库下拉框严格保持空白未选中占位状态（“选择图片/文档/视频”），并切断本地上传对资产库下拉状态的隐式污染。
