# Scenara 0.3.0-dev.8 发布说明

本版本在不引入真实模型制品的前提下，完成数据治理与审计运营闭环，并将能力同步到 API、OpenAPI、Python SDK、TypeScript SDK 和 Console。

## 数据集治理

- 新增数据集目录、数据集描述和归档状态。
- 新增可追溯的数据集版本，绑定资产清单、Manifest SHA-256、质量评分、血缘和标注摘要。
- 版本支持 `draft -> validated -> published -> retired` 生命周期，发布前必须具备资产清单和质量评分。
- 新增 PostgreSQL 迁移 `0007_dataset_governance.sql`，Memory/PostgreSQL 状态层保持同一契约。
- Console 新增“数据集治理”工作区，可创建数据集、选择资产、创建版本并执行校验/发布/退役。

## 审计中心

- 新增租户/项目隔离的审计事件查询，支持操作、资源类型、主体、结果和时间范围筛选。
- 新增 JSON、CSV 审计导出，导出受统一权限策略约束，并限制单次导出规模。
- Console 新增“审计中心”工作区，支持筛选、刷新和留档导出。

## 保存检索

- 新增保存检索资源，文本查询和人像资产查询使用同一版本化定义。
- 支持创建、更新、分页查看、执行和删除，并记录创建、更新、执行查询和删除审计事件。
- 新增 PostgreSQL 迁移 `0008_saved_searches.sql`；Console 检索工作区可直接保存和复用查询。

## SDK 与契约

- OpenAPI 增加数据集、数据集版本、审计事件和保存检索 schema/paths。
- Python SDK 增加数据集 CRUD、版本生命周期、审计查询和导出方法。
- Python/TypeScript SDK 增加保存检索的读取、更新、执行和删除方法，并允许 `PATCH` 传输方法。
- TypeScript SDK 增加相同的数据集、审计和治理资源方法。
- 产品矩阵、访问底座和实施矩阵更新为当前完成范围；真实模型准入、ANN 生产加速、Edge/Agent 等外部或门禁能力仍保持明确状态。

## 验证

- Python 定向测试、数据集治理测试和审计 API 测试通过。
- Console 单元测试 18 项、TypeScript 类型检查、Lint 和生产构建通过。
- PostgreSQL 迁移已纳入部署迁移目录；生产模型与外部基础设施证据不在本版本伪造。
