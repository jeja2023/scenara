# Scenara 0.3.0-dev.10 发布说明

发布日期：2026-08-04

本版本将当前工作区内的认证、访问控制、控制台、API 契约、SDK、数据库迁移、部署清单和测试优化统一收口为 `0.3.0-dev.10`。本版本仍是工程开发快照，不代表 `1.0.0` 生产发布，也不伪造真实模型、外部身份联邦或商业结算证据。

## 版本与发布边界

- Python 主包、Python SDK、API 系统版本和 Python SDK User-Agent 统一为 `0.3.0.dev10`。
- npm 根包、Console、TypeScript SDK、Compose/Kubernetes 镜像标签和离线包默认标签统一为 `0.3.0-dev.10`。
- 严格发布门禁继续对软件许可证法律批准、目标硬件、真实模型/评估集、离线安装和签署证据保持 fail-closed。

## 用户名密码登录与访问安全

- 新增 `POST /api/v1/auth/login`，登录请求只接受用户名和密码，可选会话 TTL；登录页不再要求租户或项目登录参数。
- 用户密码使用独立随机盐的 scrypt 摘要保存，认证采用恒定时间比较；密码原文不会写入用户记录、审计或 API 响应。
- 新增 `scenara_user_credentials` PostgreSQL 迁移 `0010_user_credentials.sql`，Memory 与 PostgreSQL 存储保持一致。
- 登录成功后按用户状态、项目 Membership 和 Role 解析有效 scope，并签发带过期时间的交互式会话；停用用户、错误密码、无项目成员关系均拒绝登录。
- 会话认证不能通过请求头覆盖会话租户或项目上下文；既有平台根令牌和服务账号 API Key 兼容保留。
- 支持通过 `SCENARA_BOOTSTRAP_ADMIN_USERNAME` 与 `SCENARA_BOOTSTRAP_ADMIN_PASSWORD` 初始化本地管理员、组织、项目、角色和成员关系，并校验凭据必须成对配置且密码至少 12 个字符。

## Console 登录体验

- 新增独立登录路由和响应式登录页，提供用户名、密码、密码显示切换、保持登录、错误提示和安全品牌信息。
- 登录成功后返回原始目标页面，未登录访问受保护路由时自动跳转到登录页；控制台顶部新增退出登录操作。
- 会话令牌按“当前会话”或“持久登录”分别存储，连接设置不再把认证令牌明文写入普通连接配置。
- “访问”工作区创建用户时支持设置密码；登录品牌文案统一为“视觉 AI 中枢平台”。
- E2E 场景覆盖未认证重定向、用户名密码登录、错误凭据、桌面和移动端工作区加载。

## 控制面与契约同步

- 访问底座能力摘要新增用户名密码登录和交互式会话状态，统一记录认证、授权和审计边界。
- 用户模型新增可选密码创建字段，OpenAPI、Python SDK 和生成后的 TypeScript SDK 同步更新 `LoginRequest` 与相关类型。
- Console API 客户端新增登录边界，登录请求不携带 `Authorization`、`X-Tenant-Id` 或 `X-Project-Id`，其他受保护请求继续使用已解析的会话上下文。
- 既有项目生命周期审批、审计保留清理、幂等计量、席位限制、适配器健康探测和 Agent/Flow/Edge/Worker 控制面能力继续由 Memory/PostgreSQL 共享实现并纳入同一版本契约。

## 文档与部署

- 更新 README、产品矩阵、访问底座、仓库拓扑、人像战略和实现矩阵的当前版本与登录能力说明。
