# Scenara 0.3.0-dev.7 发布说明

`0.3.0-dev.7` 是索引契约与人像比对能力的完整开发版。本版本不是演示性 MVP：解析结果、身份库、特征空间和后续检索能力统一使用平台级索引契约；人像比对支持图片输入、图片资产、身份注册和图片搜索，并保留原有向量接口兼容性。

## 版本矩阵

| 组件 | 版本 |
| --- | --- |
| Python 主包 `scenara` | `0.3.0.dev7` |
| Python SDK `scenara-sdk` | `0.3.0.dev7` |

| 默认容器标签 | `0.3.0-dev.7` |

## 索引契约

- 新增 `IndexDefinition`、`IndexRecord`、`IndexSourceRef`、`IndexHit` 与 `IndexStore` 平台契约，统一描述向量、文本和多模态记录。
- Memory 与 PostgreSQL 均实现索引定义、记录 upsert、来源过滤、文本查询、向量查询、软删除和过期清理；新增迁移 `0006_index_contract.sql`。
- 解析结果完成后写入 `result.<domain>` 索引，记录资产、运行、单元、对象、页面、时间戳和裁剪产物引用；OCR 文本与文本块可以直接被后续检索消费。
- 人像身份注册同步写入 `portrait.identity.<feature_space>` 索引；图片搜索以索引契约为主查询路径，旧特征 API 保留兼容。索引记录 API 返回脱敏投影，向量只保留在服务端受保护存储中。
- 索引失败会将结果摘要标记为 `partial`，不会伪报索引已就绪。
- 索引记录携带来源、资产、运行、单元、对象、页面、时间戳和过期时间，支持来源删除、资产删除、软删除和调度器过期回收。
- 查询向量必须匹配索引声明的模型 ID、模型版本和维度；契约不一致时返回明确的索引冲突，不会静默混用不同模型的特征。

## 人像比对

- 新增 `POST /api/v1/portrait/identities/{identity_id}/enrollments/image`，从图片检测人脸、选择质量最佳人脸、提取特征并注册身份。
- 新增 `POST /api/v1/portrait/search/image`，从图片提取特征后按特征空间检索身份库。
- 新增 `POST /api/v1/portrait/compare/images`、`POST /api/v1/portrait/compare/assets`、`POST /api/v1/portrait/compare/asset-image` 和 `POST /api/v1/portrait/compare/image-asset`，覆盖图片、资产和混合输入组合。
- 新增 `POST /api/v1/search/asset`，允许统一检索直接使用图片资产作为人像查询输入；原始媒体已过期时资产入口会拒绝读取。
- 新增通用索引文本查询和向量查询接口，后续人搜图、文搜图、文搜视频可复用同一来源与结果契约。
- 比对响应包含分数、距离、阈值、特征空间、模型版本、人脸数量、选中人脸和质量摘要；不返回原始 embedding。
- 生产模式不允许无检测结果时静默使用整图 fallback；开发模式保留可审计的图像指纹 fallback，响应明确标记 `fallback`。
- 租户、项目、资产访问、索引记录和生物特征删除都沿用现有授权与审计边界。

## 统一检索

- 解析结果中的人脸特征会进入按特征空间隔离的 `result.portrait.face.*` 向量索引；向量只在服务端私有索引记录中保存，公共结果文档不会携带 embedding。
- `POST /api/v1/search/text` 支持 OCR 文本检索并按图片、视频、文档、视频流过滤；`POST /api/v1/search/image` 支持以查询图片检索已解析图片、视频帧和视频流结果。
- 检索命中返回运行、资产、单元、对象、裁剪产物和媒体类型上下文，Console 可以直接回到“解析结果”查看原始详情。
- 结果中心支持接收检索命中的运行编号和解析单元，打开视频帧或文档页时自动定位到对应单元。
- Search 现在是可用的种子能力，但生产级 ANN 加速、相关性评估、语义重排和保存检索仍属于后续门禁。

## SDK 与控制台

- Python、TypeScript SDK 增加图片注册、图片搜索、图片/资产比对、索引记录查询和通用索引向量查询方法。
- Console 新增“检索 / 人像比对”工作区：支持两侧本地图片、图片资产或混合输入，提供阈值、契约与模型摘要、相似度判定和审计反馈。
- 旧的向量注册、向量搜索和向量比对 API 保持兼容。

## 迁移与验证

- PostgreSQL 部署必须执行 `0006_index_contract.sql`。
- Python 全量回归、索引契约测试、人像图片闭环测试、Console 类型检查和 ESLint 均应通过。
- 当前版本仍属于开发版，正式生产发布仍需完成模型权利、固定评估集、GPU 容量、备份恢复和安全评估证据。

说明：向量索引记录只在服务端受保护存储中参与检索，API、Console 和 SDK 均只返回脱敏投影。
