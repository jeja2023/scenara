# Scenara 0.3.0-dev.3 发布说明

发布日期：2026-07-31

`0.3.0-dev.3` 是一次面向媒体预览、GPU 推理验证和运行契约稳定性的开发版。它修复了控制台无法显示上传图片、解析后图片、视频首帧和视频流首帧的问题，并统一了活动版本引用。本版本仍不是正式 `1.0.0` 生产发行版；合法模型、固定评估集、目标 GPU 资格、离线安装、恢复演练、软件许可证和具名签署证据仍受严格发布门禁约束。

## 本版变更

### 媒体预览

- 图片上传预览改用 Data URL，并在浏览器加载失败时回退到 FileReader。
- 图片和视频解析完成后加载服务端 JPEG 首帧；视频原始编码无法在浏览器播放时仍显示首帧。
- 新增视频流源首帧接口 `GET /api/v1/media/sources/{source_id}/preview`，控制台支持首帧和检测框叠加显示。
- MediaView 将视频预览定义为首帧预览，避免把 JPEG 响应作为 `<video>` 播放源。

### 解析语义与模型配置

- 明确解析单元语义：图片为单元，视频/流为采样帧，PDF 为页面；最大单元数是任务处理上限，不是目标数量上限。
- `max_units_reached` 告警提供中文解释和处理建议。
- 默认模型改用稳定的缓存键和别名契约；新增部署契约测试覆盖模型键、别名和能力绑定。
- 当前人像默认结果展示源图/首帧、边框和数值特征；特征向量不等于图片，裁剪特征图查看尚未作为本版本能力提供。

### 构建与运行验证

- Dockerfile 修复前端源码复制顺序，保证镜像构建时 Console 使用完整源码。
- 本地 NVIDIA Docker 环境确认 ORT 注册 TensorRT、CUDA、CPU provider，并实际以 `CUDAExecutionProvider` 在 GPU 0 加载人像模型。
- `livez`、`readyz`、图片、H264 视频和视频流首帧预览均完成实测。
