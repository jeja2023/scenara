# Scenara 0.3.0-dev.15 发布说明

发布日期：2026-08-08

`0.3.0-dev.15` 把“同一视频内连续出现”推进为“跨视频、跨摄像头的长期身份轨迹”闭环。视频内 tracklet、跨运行轨迹注册、摄像头拓扑、人工确认以及长期身份查询现在共享一套持久化契约；本版本同时把部署、SDK、OpenAPI 和文档的版本号统一启用到新开发版本。

## 轨迹与重识别闭环

- 视频内使用 tracklet 关联和片段重连，把同一人在单个视频中的连续出现稳定串起来，并将私有轨迹交给长期轨迹注册器。
- 跨视频处理使用 body + face 多模态证据，结合摄像头拓扑、最小/最大转移时间和同一时间窗口互斥约束，避免把不可能的跨机位跳转合并为同一人。
- 真实媒体时间线使用 `recording_started_at` + `pts_ms`；缺少绝对录制时间时，不把处理时刻伪装成跨运行的权威时间，只在同一运行内使用相对时间约束。
- 摄像头在轨迹摄入时自动登记，长期身份、轨迹片段、时间线和摄像头来源均可通过 API 查询；Console 提供确认、否决、命名、合并、拆分和连带生物特征删除的人工审查入口。
- 公共结果保留长期身份字段和片段定位信息，不泄露原始 embedding；`/api/v1/parse/video` 快捷入口同步支持 `camera_id` 与 `recording_started_at`。
- 新增真实双 AVI 视频 E2E：第一段视频创建新身份，第二段视频在另一摄像头上完成 ReID，最终身份 API 返回一个长期身份和两段跨摄像头轨迹。

## 版本与文档同步

- Python 主包、Python SDK、API 系统版本和 Python SDK User-Agent 启用 `0.3.0.dev15`。
- npm 根包、中文 Console、TypeScript SDK、Compose/Kubernetes 镜像和离线包默认标签启用 `0.3.0-dev.15`。
- README、更新日志、实现矩阵、Portrait 能力矩阵、访问底座、产品矩阵、仓库拓扑和人像智能战略文档同步到新版本。
- 发布门禁改为检查 `docs/release/0.3.0-dev.15.md`，避免实现、发布说明和部署标签脱节。

## 升级提示

1. API、Worker、Console 和离线包统一使用 `0.3.0-dev.15`，不要混用上一版镜像。
2. 需要形成跨视频的权威时间线时，应为每个视频提供稳定的 `recording_started_at` 和明确的 `camera_id`。
3. 本版本仍是开发资格快照；正式模型制品、固定评估集、目标 GPU、离线安装和法律/签署证据仍受发布门禁约束。
