# Scenara 0.3.0-dev.21 发布说明

**发布日期**：2026-08-14

`0.3.0-dev.21` 是一次对象存储治理和大文件传输升级。平台边界从具体 MinIO 实现进一步抽象为经认证的 S3 Provider 契约；MinIO 仍是当前私有化部署基线，其他供应商必须通过同一套兼容测试后才能进入认证矩阵。本版本仍是工程开发快照，不代表正式 `1.0.0` 生产发行版；模型资格、目标硬件、离线安装和签署证据仍由严格发布门禁控制。

---

## 主要变更

### 1. 经认证 S3 Provider 契约

- 新增统一对象存储协议和错误模型，Provider 不再向平台业务暴露 MinIO 专有类型。
- 新增 `tests/object_store_contract.py` 资格测试，覆盖上传、下载、并发冲突、multipart、删除、重连恢复、存在性、摘要校验和幂等重试。
- MinIO 作为当前私有化基线；AWS S3、Alibaba OSS S3 API、Ceph RGW 标记为候选 Provider，必须对真实目标版本执行资格测试并保留报告。

### 2. 不可变发布与 SHA-256 完整性

- 本地对象存储使用原子排他创建；S3 Provider 使用 `If-None-Match: *` 条件创建，multipart 完成阶段同样执行条件保护。
- 同一 key 和同一 SHA-256 的重试请求幂等；不同内容写入已发布 key 返回 `409 IMMUTABLE_OBJECT_CONFLICT`。
- 写入时保存 SHA-256 元数据并携带原生 S3 checksum；媒体、预览、结果分片、运行产物和 Redis 队列恢复读取均支持摘要校验。
- 加密内部 Secret Store 明确使用 `overwrite=True`，保留为唯一需要更新语义的对象类别。

### 3. 安全、凭证和生命周期

- 支持 AWS 默认凭证链、实例角色、STS session token、静态凭证、TLS、自定义 CA、SSE-S3 和 SSE-KMS。
- 支持 `auto`、`path`、`virtual` 三种 S3 addressing style，适配 MinIO、OSS 和云端 S3 网关。
- 原始媒体、预览图、结构化结果和临时上传使用独立 retention tag；数据库 retention scheduler 仍是权威，Provider 生命周期规则延迟一天作为安全网，未完成直传对象一天后过期。

### 4. 大文件预签名直传与下载

- 新增 `POST /api/v1/media/uploads/presign`，将上传 URL 绑定到租户、项目、文件名、类型、大小、SHA-256 和过期时间。
- 新增 `POST /api/v1/media/uploads/complete`，完成对象完整性验证后再创建媒体资产并清理临时对象。
- 新增 `GET /api/v1/media/assets/{asset_id}/download-url`，授权并校验摘要后返回短期下载 URL。
- Python SDK 新增 `upload_asset_direct`；TypeScript SDK 新增 `uploadAssetDirect`，均使用独立 HTTP 连接直接传输对象内容。

### 5. 文档、部署和版本同步

- 新增 [对象存储提供商认证.md](../对象存储提供商认证.md)，补充 Provider 认证、凭证、TLS、SSE、生命周期和直传运维说明。
- ADR、README、支持矩阵、实现矩阵、OpenAPI、Compose、Kubernetes、离线包和发布门禁统一切换到本版本。

## 升级与兼容性说明

1. 默认开发环境仍使用本地对象存储；预签名 API 只有在 `SCENARA_OBJECT_BACKEND=s3` 且 `SCENARA_S3_PRESIGNED_URLS_ENABLED=true` 时开放。
2. 启用预签名直传时，必须配置客户端可访问的 `SCENARA_S3_PUBLIC_ENDPOINT_URL`，并让签名凭证具有对象写入、读取和摘要校验所需权限。
3. 启用 `SCENARA_S3_LIFECYCLE_ENABLED=true` 前，确认 Provider 身份拥有 `PutBucketLifecycleConfiguration` 权限；否则由外部平台配置等价生命周期规则并保持该开关关闭。
4. 已有对象记录继续以 PostgreSQL 中的 SHA-256 为权威。升级后新写入对象会自动保存服务端摘要；恢复旧对象时应先通过 `verify` 或实际读取完成资格校验。
5. 镜像、Compose、Kubernetes 与离线部署的默认标签升级为 `0.3.0-dev.21`。新的发布证据需要针对本版本重新执行，历史 `0.3.0-dev.20` 证据报告保持不变。
