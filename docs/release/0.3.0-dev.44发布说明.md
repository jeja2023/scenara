# Scenara 0.3.0-dev.44 发布说明

`0.3.0-dev.44` 聚焦于生产与开发环境配置模板全面对齐、四仓库解耦下的数据平台委托验签接入、共享基础设施网络治理及持续集成部署契约加固。公开 `/api/v1` 接口契约与数据模型保持完全兼容。

---

## 主要变更

### 1. 环境变量配置模板全面对齐

- **开发模板对齐**：
  - 在根目录 `.env` 中完整对齐 `.env.example`，补齐数据平台委托身份上下文签名密钥 `SCENARA_DATA_CONTEXT_SIGNING_KEY=`。
  - 同步中文配置注释，明确该密钥用于 Core 签发给独立 Data 服务的委托身份 HMAC-SHA256 上下文签名。
- **生产配置对齐**：
  - 完整对齐 `deploy/.env.production` 与 `deploy/.env.production.example`，同步镜像标签至 `0.3.0-dev.44`。
  - 补齐平台共享容器网络 `SCENARA_PLATFORM_NETWORK=scenara-platform`。
  - 接入强随机 `SCENARA_DATA_CONTEXT_SIGNING_KEY`（生产模式下强制要求 >= 32 字符），消除生产校验阻断。
  - 将属于共享基础设施（`deploy/shared-infra/`）管理的 MinIO 根管理员账密（`SCENARA_MINIO_ROOT_USER` / `SCENARA_MINIO_ROOT_PASSWORD`）从 Core 生产环境变量及校验器中解耦，遵循最小权限原则仅保留 Core 的 S3 访问密钥。
- **配置生成与校验工具强化**：
  - 更新 `scripts/validate_production_config.py`：在 `REQUIRED` 与 `SECRET_NAMES` 必填和机密集合中加入 `SCENARA_DATA_CONTEXT_SIGNING_KEY`，移除已被剥离的 MinIO 根管理员账密。
  - 更新 `scripts/generate_production_env.py`：支持一键自动生成高强度 `SCENARA_DATA_CONTEXT_SIGNING_KEY` 随机令牌。

### 2. 数据平台委托身份上下文与签名验证

- **HttpDataPlatformClient 上下文委托验签**：
  - 在 `scenara/platform/data_platform.py` 中接入委托身份上下文签名逻辑：Core 调用独立 Data 服务时，自动计算并携带 `x-scenara-context-signature` 与 `x-scenara-context-timestamp`。
  - 数据模型层支持 `PrincipalContext` 携带租户、项目、主体、权限范围（scopes）、产品权益（entitlements）、请求跟踪标识（trace_id）以及时间戳。
  - 单元测试与端到端集成测试全面覆盖签名生成、时间窗口校验以及跨独立服务边界的委托身份传递。

### 3. 部署架构解耦与共享基础设施演进

- **共享基础设施提取**：
  - 确立 `deploy/shared-infra/compose.yml` 作为共享基础设施（PostgreSQL、Redis、MinIO）的独立定义，创建统一的 `scenara-platform` 容器网络。
  - Core、Data、Model 等独立仓库作为客户端接入该平台网络，通过专用账号与最小权限 Policy（如 Core 的 `core-policy.json`）隔离资源。
- **持续集成与部署契约加固**：
  - 更新 `tests/test_deploy_ci_contract.py`：适配解耦后的架构，明确 `deploy/compose.yml` 验证 Core 服务（migrate, api, workers, scheduler）与 platform 网络，`deploy/shared-infra/compose.yml` 验证基础设施组件的 digest-pinned 镜像与账号隔离。
  - CI 工作流 `.github/workflows/ci.yml` 完整覆盖共享基础设施与独立服务的备份、恢复及端到端集成演练。

### 4. 版本号体系一致性

- 全平台统一推进至 `0.3.0-dev.44`（Python 为 `0.3.0.dev44`）：
  - 同步更新 Python 包（Core, Data, SDK）、Node.js 包（Console, TS SDK）、OpenAPI 契约声明、Docker 镜像构建参数、Compose 编排文件以及 Kubernetes 全套清单（Kustomization, API, Migrate, Scheduler, Workers）。
  - 通过 `tests/test_version_consistency.py` 严格一致性校验。

## 升级指南

1. **容器镜像与编排**：
   - 镜像标签升级为 `0.3.0-dev.44`。
   - 若使用生产 Compose 部署，请确保已启动 `deploy/shared-infra/compose.yml`，并确保环境变量包含 `SCENARA_PLATFORM_NETWORK=scenara-platform`。
2. **安全密钥配置**：
   - 在生产环境配置文件中，必须配置长度不少于 32 字符的 `SCENARA_DATA_CONTEXT_SIGNING_KEY`。可使用 `python scripts/generate_production_env.py` 自动生成。
3. **环境校验**：
   - 部署前执行 `python scripts/validate_production_config.py --env-file /path/to/scenara.env` 验证无遗漏项。
