# Scenara 0.3.0-dev.11 发布说明

发布日期：2026-08-05

本版本在 `0.3.0-dev.10` 用户名密码登录基线之上，完成“领域与能力”页面的全面中文化和信息层级优化，并将项目根环境变量模板升级为可直接指导开发与生产配置的中文文档。本版本仍是工程开发快照，不代表 `1.0.0` 生产发布，也不改变真实模型、目标硬件、离线安装和签署证据的严格门禁。

## 版本与发布边界

- Python 主包、Python SDK、API 系统版本和 Python SDK User-Agent 统一为 `0.3.0.dev11`。
- npm 根包、Console、TypeScript SDK、Compose/Kubernetes 镜像标签和离线包默认标签统一为 `0.3.0-dev.11`。
- 本版本不新增公共 API、数据库迁移或破坏性契约，现有 `0.3.0-dev.10` 登录与访问控制接口保持兼容。
- 严格发布门禁继续对软件许可证法律批准、目标硬件、真实模型与评估集、离线安装和签署证据保持失败关闭。

## 领域与能力页面中文化

- 领域名称和说明统一通过前端标签层转换为中文，后端返回的英文显示名、英文说明和技术标识不再直接暴露给用户。
- 人像与 OCR 文档领域提供固定中文说明；未知领域仅在后端已提供中文名称或说明时展示，否则使用安全的中文兜底文案。
- 流水线名称、版本和状态改为面向用户的中文展示，未知流水线使用“自定义解析流水线”，不再展示内部流水线编号。
- 页面新增已安装领域数、可用流水线数、支持的数据类型、已启用能力和可用解析流水线分区，并补齐空状态提示。
- 工作区入口根据领域名称动态生成中文按钮文案，领域和流水线按中文名称稳定排序。
- 新增标签层单元测试和 Playwright 场景，专门阻止后端英文文案、领域编号和流水线编号泄漏到页面。

## 环境配置与本地管理员

- 根目录 `.env.example` 的注释全面改为中文，41 个环境变量按运行模式、认证、资源限制、模型与加密、企业策略、网络安全、数据保留、运行产物和生产后端分组说明。
- 每项配置补充用途、生效条件、可选值、数值范围、容量或时间单位以及生产环境风险提示。
- 补充此前缺失的 `SCENARA_OCR_ENGINE_FACTORY` 示例，移除重复的 `SCENARA_SECRET_ENCRYPTION_KEY`，并将密码与密钥改为不可直接用于生产的安全占位值。
- README 本地启动流程增加 `.env.example` 到 `.env` 的生成步骤，并通过 `--env-file .env` 显式加载配置。
- 明确 `SCENARA_BOOTSTRAP_ADMIN_USERNAME` 与 `SCENARA_BOOTSTRAP_ADMIN_PASSWORD` 必须同时配置，管理员密码不得少于 12 个字符。
- 本地 `.env` 保持 Git 忽略；随机管理员密码、平台根令牌和 Fernet 密钥不进入版本库、更新日志或发布制品。

## 文档与部署

- 更新 README、中英文更新日志、实现矩阵、产品矩阵、访问底座、仓库拓扑和人像长期战略的当前适用版本。
- Compose、Kubernetes、生产环境变量模板、离线包脚本和部署示例的默认镜像标签升级为 `0.3.0-dev.11`。
- 发布门禁改为校验 `docs/release/0.3.0-dev.11发布说明.md`，历史发布说明保持不变。
