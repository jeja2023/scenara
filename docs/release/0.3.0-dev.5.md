# Scenara 0.3.0-dev.5 发布说明

`0.3.0-dev.5` 是面向解析工作区信息架构、领域扩展和端到端使用效率的开发版。它把解析入口组织为“领域 -> 媒体类型 -> 解析工作区”，并保持上传、配置、运行、结果和历史在同一个领域媒体上下文内完成。本版本仍不是正式 `1.0.0` 生产发行版，严格发布门禁和生产模型资格要求保持不变。

## 版本矩阵

| 制品 | 版本 |

## 解析工作区与导航

- 解析菜单按领域和媒体类型动态展开，例如“人像 -> 图片/视频/视频流”和“OCR -> 图片/文档”。
- 新增 `/parse/{domain}/{media_kind}` 叶子路由；同一工作区完成上传、媒体库选择、参数配置、运行控制、结果查看和当前媒体类型历史。
- 领域菜单使用 `DomainManifest.supported_media_kinds` 自动生成，新增领域不需要修改前端侧栏代码。
- 解析页增加当前领域/媒体类型上下文栏，可在同领域媒体类型之间快速切换。
- 保留 `/portrait`、`/ocr`、`/parse?domain=...` 和 `/parse?run=...` 等历史入口兼容跳转。
- 全局“媒体”和“运行”页面继续承担资源管理与跨领域历史查询，不再成为普通解析流程的必经步骤。

## 运行与结果

- 解析页展示当前领域、媒体类型下的最近运行，并支持直接恢复运行上下文。
- 历史列表按领域和媒体类型收敛，避免用户在跨页面列表中重新寻找任务。
- 后端接口返回不完整或暂不可用时，前端列表统一归一化为空集合，保持可操作的空状态，不产生渲染异常。
- 动态流水线参数继续由 `parameter_schema` 驱动，新领域可以复用通用结果展示器。
