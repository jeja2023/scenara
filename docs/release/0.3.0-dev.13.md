# Scenara 0.3.0-dev.13 发布说明

发布日期：2026-08-05

`0.3.0-dev.13` 是一次面向中文用户体验和工程文案一致性的开发版本。在保持 `/api/v1` 契约、字段、枚举值和模型标识兼容的前提下，本版本完成后端提示、前端界面、CLI 帮助、产品目录和代码注释的全面中文化，并同步更新所有版本制品与部署文档。

## 中文化范围

- 后端调度器、工作进程、动态批处理队列和运行时错误提示改为中文，保留错误码、环境变量名和协议字段不变。
- OCR、人像领域插件的产品范围、领域说明和能力描述改为中文，用户不再直接看到英文产品介绍。
- 产品目录中的摘要、当前范围、未纳入范围和下一道门禁改为中文，覆盖 Parse、Model、Data、Console、API、SDK、Index、Search、Flow、Edge 和 Agent。
- 前端控制台残留英文界面文本、登录页标题、媒体预览错误、资源加载错误和可见注释改为中文。
- 后端平台模型、控制面、服务层、运行时和前端 composables 中的英文注释改为中文，技术缩写仅在需要保持准确性的场景保留。
- 修复前端资源加载提示中的乱码文本，统一使用 UTF-8 中文文案。

## 兼容性与版本

- Python 主包、Python SDK、API 系统版本和 User-Agent 统一为 `0.3.0.dev13`。
- npm 根包、Console、TypeScript SDK、Compose/Kubernetes 镜像和离线包默认标签统一为 `0.3.0-dev.13`。
- `/api/v1` 路径、请求字段、响应字段、错误码、枚举值和数据库迁移保持兼容。
- `API`、`OCR`、`SDK`、`OpenAPI`、`HTTP`、`HTTPS`、`JSON`、`CSV`、`SHA-256`、`CUDA`、`CPU`、`GPU` 等标准技术标识保留原文，避免影响集成、检索和运维。

## 文档同步

- 更新 `README.md`、`CHANGELOG.md`、`更新日志.md`、产品矩阵、访问底座、仓库拓扑、人像战略和部署示例中的当前版本号。
- 更新 OpenAPI 版本信息、Python/TypeScript SDK 包版本、Compose/Kubernetes 镜像标签和离线安装包默认标签。
- 发布说明本身使用中文记录变更，后续版本继续沿用“中文说明 + 稳定协议标识保留”的原则。

## 验证结果

- `py -m compileall -q app scenara scripts` 通过。
- `pnpm --dir frontend/console run build` 通过。
- `git diff --check` 通过。
- Python 测试未能进入收集阶段，当前执行环境缺少 `cv2` 依赖，报错为 `ModuleNotFoundError: No module named 'cv2'`；需要安装完整开发依赖后再运行全量测试。
- 前端构建使用当前 Node `v24.14.0`，项目声明范围为 `>=22.22.2 <23`；本次构建成功，但建议 CI 和发布环境使用声明范围内的 Node 版本。

## 升级提示

1. 使用 `0.3.0-dev.13` 镜像或离线包标签部署。
2. 更新 Python/Node 依赖时保持 `0.3.0.dev13` 与 `0.3.0-dev.13` 的格式对应关系。
3. 安装完整开发依赖（包括 OpenCV）后执行 Python、Console、SDK 和 E2E 测试。
4. 本版本仍是开发快照，不代表 `1.0.0` 生产资格；严格发布门禁、模型制品和法律/签署证据要求继续有效。
