# Scenara 0.3.0-dev.9 发布说明

发布日期：2026-08-04

本版本是继 `0.3.0-dev.6` 之后的累计工程发布，完整收录 dev.7、dev.8 和本次 P0-P2 收口改动。除真实模型制品、模型训练和模型评估外，计划中的非模型开发能力已全部落地并同步到服务端、迁移、OpenAPI、Python SDK、TypeScript SDK、Console、部署示例和文档。

## 版本与发布边界

- Python 主包、Python SDK、API 系统版本和 Python SDK User-Agent 统一为 `0.3.0.dev9`。
- npm 根包、Console、TypeScript SDK、Compose/Kubernetes 镜像标签和离线包默认标签统一为 `0.3.0-dev.9`。
- 真实模型调用、模型训练、固定评估集、目标 GPU 容量和模型权利证明不在本版本伪造；它们仍由模型制品和正式发布证据门禁控制。

## 解析、结果与人像检索

- 解析控制台采用领域工作区结构，图片、视频、文档和实时流在领域上下文内切换，结果中心支持跨领域、跨运行浏览。
- Index 提供租户/项目隔离的索引定义、来源引用、文本/向量查询、软删除、保留和重建契约。
- Search 支持文本、人像、图片资产和跨媒体结果检索，命中结果保留运行编号、解析单元和来源定位。
- 新增图片人像注册、图片搜索、图片比对和图片资产比对；生产请求严格校验模型 ID、版本、维度和特征空间，开发 fallback 仍显式标记。
- 支持保存检索、加权排序 Profile、相关性反馈、检索评估和结果来源回溯；真实 ANN、语义重排和跨租户联邦仍保持门禁状态。

## 数据治理与审计

- 新增数据集目录、不可变数据集版本、资产 Manifest SHA-256、质量评分、血缘和标注摘要。
- 数据集版本支持 `draft -> validated -> published -> retired`，发布前执行资产清单和质量契约校验。
- 新增标注任务/审核及标注服务适配器注册、列表和健康探测。
- 审计中心支持租户/项目隔离查询、操作/资源/主体/结果/时间筛选、JSON/CSV 导出、保留策略和 dry-run/execute 清理。
- 新增迁移 `0007_dataset_governance.sql`、`0008_saved_searches.sql`、`0009_control_plane_records.sql` 和 `0010_user_credentials.sql`，Memory/PostgreSQL 共享同一控制面语义。

## IAM、治理与商业化控制面

- 支持用户名密码登录、身份提供者记录和 OIDC/SAML/SCIM 配置探测；密码使用带独立随机盐的 scrypt 摘要，交互式会话在登录时校验用户状态并解析项目 Membership/Role scope。
- 项目停用、恢复和删除必须创建审批请求并记录批准/拒绝审计；租户管理员支持跨项目审核。
- 配额计划、用量检查、计费账户、幂等 Meter Event、用量聚合和席位上限已形成统一 API 契约。
- 支付结算、发票、税务、自助购买和真实外部身份签名交换仍需部署方绑定正式外部服务，不由开发快照伪造。

## Flow、Edge、Agent 与平台运维

- Flow 支持运行定义、条件、人工审批、Webhook 和执行状态记录。
- Edge 支持设备注册、证书指纹、心跳、部署引用、离线同步和部署确认。
- Agent 支持工具注册、最小权限动作、审批和审计执行，并新增 Trace、Evaluation 与租户/项目作用域的 TTL Memory。
- Worker 支持租约、拓扑、心跳和部署状态查询；同时提供 Kubernetes 预生产拓扑清单。

## API、SDK 与 Console

- 所有新资源同步到 `/api/v1`、OpenAPI、Python SDK 和 TypeScript SDK，并提供生成后的 TypeScript `dist` 发布制品。
- Console 新增“数据集治理”“审计中心”“检索”“人像比对”“平台治理”等工作区，保持中文优先、桌面/移动端响应式布局和统一授权边界。
- 新增开发门禁 `scripts/development_gate.py`，实现发布门禁支持 `--implementation-only`，严格发布门禁继续 fail-closed。
