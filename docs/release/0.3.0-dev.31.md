# Scenara 0.3.0-dev.31 发布说明

`0.3.0-dev.31` 聚焦于解析工作台交互体验与信息架构的全面优化，包括原地全功能结果详情抽屉、紧凑参数表单排布、元素遮挡修复、环境配置文件严格对齐以及侧边栏导航分组顺序优化。

## 主要成果

### 1. 解析工作台交互重构与详情抽屉
- **原地全功能结果抽屉** ([frontend/console/src/components/ResultDetailDrawer.vue](file:///d:/project/scenara/frontend/console/src/components/ResultDetailDrawer.vue))：
  - 将解析结果查看与回看工作区封装为独立的抽屉组件，支持在解析工作台（`ParseView.vue`）和结果列表（`ResultsView.vue`）两处无缝复用。
  - 在工作台最近运行表中点击「详情」或解析完成后的「查看结构化结果」时，直接在当前页面右侧滑出抽屉，无需页面跳转即可随时查阅。
  - 抽屉内置：结构化指标与技术元数据、时间轴单元序列切换、特征图切片图库（支持 Lightbox 大图查看）、目标明细表、OCR 文本预览与 JSON/CSV 格式导出。
- **工作台界面精简去重** ([frontend/console/src/views/ParseView.vue](file:///d:/project/scenara/frontend/console/src/views/ParseView.vue))：
  - 移除工作台主界面冗余的特征图与时间轴面板，使其专注于音视频/图片/文档的输入配置与实时处理；
  - 移除顶部冗余的导出按钮与详情头部冗余的跳转按钮，统一通过详情抽屉进行数据导出与回看。

### 2. 参数表单紧凑排布与遮挡修复
- **参数栅格紧凑排布** ([frontend/console/src/views/ParseView.vue](file:///d:/project/scenara/frontend/console/src/views/ParseView.vue))：
  - 重构 `.parameter-grid` 为自适应弹性网格（`repeat(auto-fill, minmax(130px, 1fr))`），控件高度精简至 `32px`；
  - 支持领域参数（重叠阈值、最低置信度、最大目标数）以及采样参数（采样策略、采样间隔、起始/结束时间、边长、超时阈值等）一行并排展示 2~4 个，大幅降低纵向空间占用。
- **元素遮挡与层级修复**：
  - 修复视频流登记选择框被刷新按钮绝对定位覆盖的问题，规范为栅格对齐的后缀按钮容器；
  - 修复图片模式下「领域参数」标题文字与上方分割线/第一个输入框重叠的问题，增加标准间距保护；
  - 优化顶部流水线选择与工作区操作按钮在窄屏与展开状态下的响应式排布。

### 3. 左侧导航栏层级优化
- **信息架构与导航顺序调整** ([frontend/console/src/router.ts](file:///d:/project/scenara/frontend/console/src/router.ts), [frontend/console/src/App.vue](file:///d:/project/scenara/frontend/console/src/App.vue))：
  - 将「智能检索」分组提升至「数据与分析」分组上方，形成“核心工作区 -> 智能检索 -> 数据与分析 -> AI 引擎与模型 -> 平台治理与系统”的高效作业动线。

### 4. 环境变量配置文件对齐
- **环境配置严格一致** ([.env.example](file:///d:/project/scenara/.env.example))：
  - 彻底对齐 `.env.example` 与 `.env` 的配置项结构与行数，保持严格 1:1 一致，移除冗余配额与过时配置项。
