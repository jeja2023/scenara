# Scenara 0.3.0-dev.36 发布说明

`0.3.0-dev.36` 重点聚焦于**比对预警与布控系统完整落地**、**控制台全局数据表格与页面视图深度重构**，以及**平台原生备份恢复与多场景本地演练套件增强**。

## 主要成果

### 1. 比对预警与布控系统完整落地 (Surveillance & Watchlist Alert System)
- **三阶段研发计划与顶层设计** ([docs/布控告警开发方案.md](file:///d:/project/scenara/docs/布控告警开发方案.md))：
  - 制定了《Scenara 比对预警与布控功能研发计划与任务分解》，明确定义了核心底座与比对预警引擎 (Phase 1)、控制台可视化与实时预警中心 (Phase 2)、轨迹联动时空研判与算法自闭环 (Phase 3) 的清晰演进路线。
- **数据模型与领域服务** ([scenara/platform/surveillance.py](file:///d:/project/scenara/scenara/platform/surveillance.py), [scenara/domains/portrait/surveillance.py](file:///d:/project/scenara/scenara/domains/portrait/surveillance.py))：
  - 落地了布控名单库（`Watchlist`，支持黑名单/白名单/自定义组）、布控目标档案（`WatchlistTarget`）、布控任务（`SurveillanceTask`）与实时预警记录（`AlertRecord`）；
  - 支持多模态加权融合比对（人脸 Face + 人体 ReID）与基于 `FeatureStore`（pgvector / Qdrant）的 1:N 向量 Top-K 毫秒级检索；
  - 引入了基于 `(target_id, camera_id)` 冷却窗口的滑动频控与告警去重抑制机制（Debounce），有效避免同一目标在摄像头前停留时引发告警风暴。
- **存储与数据迁移** ([scenara/infrastructure/memory_surveillance.py](file:///d:/project/scenara/scenara/infrastructure/memory_surveillance.py), [scenara/infrastructure/postgres_surveillance.py](file:///d:/project/scenara/scenara/infrastructure/postgres_surveillance.py))：
  - 提供内存态与 PostgreSQL 双存储后端实现，支持租户/项目完全隔离与版本化并发保护；
  - 新增数据库迁移脚本 `migrations/0014_surveillance_alerts.sql` 与 `migrations/0015_surveillance_debounce_aggregates.sql`。
- **接口与事件扩展**：
  - REST API 完整覆盖名单库管理、目标录入、布控任务调度、告警记录多维检索与研判处置（`confirmed` / `false_positive` / `ignored`）；
  - Webhook 事件扩展支持 `alert.triggered` 与 `alert.triaged`。
- **控制台全套交互视图** ([frontend/console/src/views/surveillance/](file:///d:/project/scenara/frontend/console/src/views/surveillance/))：
  - 交付名单库管理、布控任务调度向导、实时预警大屏、告警历史与人工研判看板页面；
  - 配合前端 API 模块 [frontend/console/src/api/surveillance.ts](file:///d:/project/scenara/frontend/console/src/api/surveillance.ts) 与路由集成。
- **本地演练与测试套件**：
  - 交付本地布控与告警全流程演练脚本 [scripts/run_surveillance_local_simulation.py](file:///d:/project/scenara/scripts/run_surveillance_local_simulation.py) 与自动化测试 [tests/test_surveillance.py](file:///d:/project/scenara/tests/test_surveillance.py)。

### 2. 控制台全站表格与数据视图深度重构 (Console Fullstack Refactoring)
- **表格布局与标准行高对齐**：
  - 全面重构并优化了解析结果（`ResultsView.vue`）、长期轨迹（`TrajectoryView.vue`）、数据集治理（`DatasetView.vue`）、接入与权限（`AccessView.vue`）、资源与安全（`GovernanceView.vue`）等业务页面的表格呈现；
  - 数据表格单元格严格单行展示，彻底消除垂直挤压与不规则折行，严格对齐全局 28px 标准行高与边框规范；
  - 优化解析结果列宽分配，收紧解析成果概况列宽度至 200px，释放剩余横向空间给资源名称列；
  - 修复 `TrajectoryView` 泛型类型报错并清理 `DatasetView` 未使用的 `Database` 导入，全面统一全局 Tabs、紧凑按钮与分页控件规范。

### 3. 平台原生备份恢复与多场景本地演练套件增强 (Platform Drills & Tooling)
- **本地原生演练脚本**：
  - 新增本地原生备份恢复演练脚本 [scripts/local_native_backup_restore_drill.py](file:///d:/project/scenara/scripts/local_native_backup_restore_drill.py)；
  - 新增数据平台切流仿真演练脚本 [scripts/run_local_data_cutover_simulation.py](file:///d:/project/scenara/scripts/run_local_data_cutover_simulation.py)；
  - 新增证据流仿真脚本 [scripts/run_local_evidence_pipeline_simulation.py](file:///d:/project/scenara/scripts/run_local_evidence_pipeline_simulation.py)；
  - 新增流式协议仿真演练脚本 [scripts/run_local_stream_protocol_simulation.py](file:///d:/project/scenara/scripts/run_local_stream_protocol_simulation.py)。
- **SDK 与契约同步**：
  - Python SDK 与 TypeScript SDK 对应完成模型与客户端同步更新。
