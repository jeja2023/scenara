# Scenara 0.3.0-dev.40 发布说明

`0.3.0-dev.40` 是 `0.3.0-dev.39` 之后的跨平台兼容性、后端模块化和 Console 体验增强版本。本版本不改变公开 API 路径，重点完成布控系统收尾、实时告警可靠性和受保护媒体预览。

## 主要变更

### 跨平台与测试收尾

- `SurveillanceSchedule` 将 `UTC`、`GMT` 和 `Etc/UTC` 归一化为固定 `UTC`，Windows 未安装 tzdata 时仍可创建和执行默认布控计划；其他时区继续要求有效 IANA 标识。
- 媒体采样测试接受 `decoder_pts` 和 `position_msec` 两种合法时间戳来源，避免将 OpenCV 构建差异误判为功能回归。
- OpenAPI、SDK、Data 服务、部署入口和证据清单统一到 `0.3.0-dev.40` / `0.3.0.dev40`。

### 后端 Router 模块化

- 新增 [surveillance.py](../../scenara/api/routers/surveillance.py)，迁移：
  - Watchlist/Member 创建、查询、更新、删除；
  - Surveillance Task 生命周期；
  - Alert 列表、详情、研判、误报反馈；
  - Alert Live SSE 流。
- `server.py` 仅保留应用组装、跨领域基础路由和异常处理；布控端点通过 `build_surveillance_router` 注入，原 URL、鉴权和 envelope 不变。
- 新增 [views/access/types.ts](../../frontend/console/src/views/access/types.ts)，将 Access 页面核心类型从超大视图中抽离。
- 新增 [views/access/config.ts](../../frontend/console/src/views/access/config.ts)，将默认产品目录、权限预设、事件选项和 Tab 定义从数据编排逻辑中抽离。

### Console 性能与可靠性

- 新增 `useDebouncedRef`，任务和名单搜索采用 180ms 防抖，减少快速输入期间的重复过滤和重渲染。
- 任务和名单列表最多渲染 500 条，并在超出时提示使用状态/类别/关键字筛选；服务端列表接口仍使用分页上限。
- Live Alert Center 在 SSE 失败或自然结束后自动指数退避重连，组件卸载会清理连接和定时器。
- 告警实时流和历史列表通过 `apiImageDataUrl` 携带认证请求抓拍图；失败时显示统一占位、错误状态和重试按钮。
- Feature Crop Gallery 的裁剪图加载失败时可点击重试，避免破损图标和不可恢复的空白卡片。

## 兼容性说明

1. 所有公开 `/api/v1/surveillance/*` 路径、请求模型和响应 envelope 保持兼容。
2. UTC/GMT 输入会归一化为 `UTC`；自定义时区仍需系统 tzdata 或 Python tzdata 包支持。
3. 列表超过 500 条时前端只渲染前 500 条，需使用筛选条件缩小结果；数据不会被删除。
4. 抓拍图片现在使用带认证的二进制请求，解决 Bearer 鉴权场景下原生 `<img>` 无法加载的问题。
