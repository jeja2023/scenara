# Scenara 0.3.0-dev.27 功能完成总结

## 概述

本次开发完成了 **OCR 文档识别** 和 **行为识别** 两个完整的领域功能,使用百度飞桨(PaddlePaddle)生态系统提供生产级解决方案。

## ✅ 已完成功能

### 1. OCR 文档识别领域

**核心能力**:
- ✅ 文本检测和识别
- ✅ 版面分析(标题、段落、图片、表格)
- ✅ 表格结构化识别
- ✅ 多语言支持(中/英/日/韩)
- ✅ PDF 原生文本提取
- ✅ 参数化控制
- ✅ 质量评估框架

**技术栈**:
- PaddleOCR 2.9.2
- PaddlePaddle 3.0.0
- pdfplumber 0.11.5

**关键文件**:
- `scenara/domains/ocr/paddle_production.py` - 生产引擎
- `scenara/domains/ocr/operators.py` - 算子实现
- `scenara/domains/ocr/plugin.py` - 插件定义
- `scenara/domains/ocr/evaluation.py` - 评估框架

### 2. 行为识别领域

**核心能力**:
- ✅ 动作识别(50+ 类别)
- ✅ 时序建模
- ✅ 异常行为检测
- ✅ 活动分割
- ✅ 流式处理
- ✅ 质量评估框架

**技术栈**:
- PaddleVideo 2.5.0
- PaddlePaddle 3.0.0
- OpenCV 4.10.0

**关键文件**:
- `scenara/domains/behavior/paddle_production.py` - 生产引擎
- `scenara/domains/behavior/operators.py` - 算子实现
- `scenara/domains/behavior/plugin.py` - 插件定义
- `scenara/domains/behavior/evaluation.py` - 评估框架

## 📊 领域对比

| 维度 | Vision | OCR | Behavior |
|------|--------|-----|----------|
| **输入** | 单帧图像 | 图像/文档 | 时序视频 |
| **输出** | 检测框+特征 | 文本+版面 | 行为+时间 |
| **时序依赖** | 无 | 无 | **强** |
| **推理时间** | ~20ms | ~200ms | ~50-150ms |
| **VRAM 需求** | ~2GB | ~4GB | ~4-6GB |
| **模型框架** | ONNX | PaddleOCR | PaddleVideo |
| **媒体类型** | image/video/stream | document/image | **video/stream** |
| **导航顺序** | 10 | 20 | 30 |

## 🚀 快速开始

### 安装依赖

```bash
# OCR 文档识别
pip install paddlepaddle-gpu==3.0.0 paddleocr==2.9.2 pdfplumber==0.11.5

# 行为识别
pip install paddlepaddle-gpu==3.0.0 paddlevideo==2.5.0 opencv-python

# 或一次性安装
pip install -r requirements.txt
```

### 快速测试

```bash
# 测试 OCR
python scripts/test_ocr_quick.py

# 测试行为识别
python scripts/test_behavior_quick.py
```

### API 使用

**OCR 文档解析**:
```bash
curl -X POST http://localhost:8000/api/v1/parse/document \
  -H "Authorization: Bearer $SCENARA_API_TOKEN" \
  -F "file=@document.pdf" \
  -F "domain=ocr" \
  -F "layout_required=true" \
  -F "min_score=0.5" \
  -F "max_pages=100"
```

**行为识别**:
```bash
curl -X POST http://localhost:8000/api/v1/parse/video \
  -H "Authorization: Bearer $SCENARA_API_TOKEN" \
  -F "file=@video.mp4" \
  -F "domain=behavior" \
  -F "temporal_window_ms=1000" \
  -F "min_confidence=0.5" \
  -F "enable_anomaly_detection=true"
```

## 📝 配置说明

### OCR 配置

```bash
# .env
SCENARA_OCR_ENGINE_FACTORY=scenara.domains.ocr.paddle_production:create_production_ocr_engine
SCENARA_OCR_MODEL_DIR=                # 可选:离线模型目录
SCENARA_OCR_VERIFY_CHECKSUMS=false   # 开发环境跳过
SCENARA_OCR_USE_GPU=true             # 使用 GPU
```

### 行为识别配置

```bash
# .env
SCENARA_BEHAVIOR_ENGINE_FACTORY=scenara.domains.behavior.paddle_production:create_production_behavior_engine
SCENARA_BEHAVIOR_MODEL_NAME=pptsm    # pptsm/pptsn/slowfast
SCENARA_BEHAVIOR_MODEL_DIR=          # 可选:离线模型目录
SCENARA_BEHAVIOR_VERIFY_CHECKSUMS=false
SCENARA_BEHAVIOR_USE_GPU=true
```
