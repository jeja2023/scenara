# Scenara 景枢品牌规范

## 名称

- 英文品牌：Scenara
- 中文品牌：景枢
- 完整写法：Scenara 景枢
- 产品类别：视觉 AI 中枢平台

## 标志

主标志采用相互汇聚的双曲面带与中心四向星，形成抽象的 `S` 和视觉中枢。它表达连接、流动、汇聚与理解，也作为整个 Scenara 产品矩阵共享的几何母体。品牌口号为“连接视觉 · 理解世界”。

### 几何基线（2026-08-15）

标准图形母体以 `64 x 64` 视图框和 `x = 32` 垂直中轴为基准：

```text
中心四向星几何中心： (32, 32)
左侧/上方曲面带：相对原始母路径向上 3 个网格单位
右侧/下方曲面带：以 (32, 32) 旋转 180° 后向下 3 个网格单位
```

两条曲面带必须保持同一曲率、角度体系和渐变定义；中心星不得随曲面带移动。该几何基线适用于全彩、深色背景、单色、应用图标、favicon、横版字标、竖版字标和 Console 内置标志。

`docs/brand/assets/scenara-mark.svg` 是浅色背景下的几何参考源文件；其他变体只能改变背景、渐变亮度或文字组合，不得重新绘制另一套 Logo 路径。使用场景不得再次旋转、拉伸或手工改变两条曲面带的相对位置。

标准全彩标志使用紫色 `#6B22F4`、电光蓝 `#2845F5` 与青色 `#12C8F4` 的规定渐变；深色背景版使用更高亮度的对应色阶。界面语义色仍沿用石墨、青绿、珊瑚、绿色和琥珀色，不因品牌标志改为蓝紫单色界面。

只允许使用仓库提供的标准全彩、深色背景、单色和应用图标资产。禁止改变几何比例、旋转、拉伸、描边、添加阴影、重排渐变、改变曲面带间距或自行从品牌展示图裁切低分辨率版本。禁止在业务页面中直接复制 SVG 路径；如需新增变体，必须从标准源文件派生并更新资产校验记录。

标志四周安全留白不得小于图形宽度的四分之一。小于 24px 时只使用图形标志，不显示中英文字标；浏览器与桌面应用使用深色底应用图标。
